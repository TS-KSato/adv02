# 5-31　取材と準備

本編初稿。甲子園2回戦、港南工業戦。日和が調べた右翼手の前進と返球（中継を越えて本塁まで届く）は、試合前のミーティングで全員に共有される。勝敗を分けるのは、平野が確認した「ライトの前で高く跳ねた打球でも、足を止めずに跳ね上がりで捕り、その足で投げる」という具体的な動きが、3塁コーチの判断に届くかどうか。確認しなかった経路でも3塁コーチは右翼を警戒しているが、高く跳ねた打球なら捕るまでに一拍あると判断して走者を回し、相手の処理に上回られる。

## 試合前：廊下の取材

1回戦の翌日、宿の食堂を出ると、廊下の長椅子に記者が2人座っていた。
俺が通ると、先に立った記者が「平野くんだね」と手帳を開いた。

記者｜昨日は最後まで、みんな監督のほうを見てたね。
普段からよく声を掛けてもらうの？

平野｜え？　うーん……それは……。

ちょうど通りかかった監督が、記者の手帳を見て足を止めた。

美空｜平野くん、これお願い。先に部屋戻ってるね。

記者は俺と監督を交互に見て、「任せてもらってるんだね」と言った。
監督はもう部屋の鍵を出していた。

平野｜はは……まあ、はい……。

食堂から日和が顔を出した。
手にしていたのは、部で試合映像を見るのに使っているタブレットだ。
港南工業の1回戦を一時停止して、俺に画面を見せた。
ライトが外野のずいぶん手前で打球を拾うところだった。

日和｜向こうのライト、拾ったら足を止めずに投げてくる。
中継を越えてホームまで来るから、2塁からでも簡単には帰れないよ。
もう1本、似た打球があったよ。

もう1人の記者も立ち上がった。先に来た人とは別の質問があるらしかった。

**選択肢：取材対応を日和と分ける／一人で取材を引き受ける**

## 事前準備：ライトの返球を見る

俺は試合の記録について答え、
普段の練習については日和に代わってもらった。
そのあいだに、食堂の端で映像を見直した。

1本目は、ライトの前で高く跳ねた打球だった。
ライトは跳ね上がりに合わせて前へ出て、
足を止めずに捕り、その足で投げた。
返球は途中の野手を越えて、捕手まで届いた。

平野｜高く跳ねても、捕るまで待ってくれないのか。

日和が戻ってくるまでに、
ライトがどの打球を、どの高さで捕ったか、ノートに書いておいた。

## 事前準備なし：取材に残る

俺は日和に「映像はあとで見せて」と言って、
廊下に残り、2人の質問に答えた。
去年の決勝のことまで聞かれて、
食堂に戻ったときには、次のミーティングが始まっていた。

## 当日：面会と守備練習

試合当日。スタンド下の通路で、面会を申し込んでいた卒業生が待っていた。
控えの選手を呼びに行こうとしたところで、
外からボールがミットに収まる音が続けて聞こえた。
港南工業の外野手が、ホームへの返球を練習している。

日和｜面会なら私が案内できるよ。外、見てくる？

**選択肢：面会の案内を日和に任せ、外野の送球を見る／面会を最後まで案内する**

## 回収：外野の送球を見る

日和に面会を頼み、グラウンドへ出た。
ノッカーは、ライトの前でわざと高く跳ねる打球を打っていた。
ライトは跳ね上がりに合わせて前へ出て、足を止めずに捕り、
そのままホームへ投げた。

捕手はほとんど動かなかった。
送球が胸の高さに届くまで、俺はライトのいた場所から目を離せなかった。

## 回収なし：面会を案内する

俺は卒業生を面会場所まで案内し、選手を連れて戻った。
グラウンドへ出たときには、
港南工業の外野手はもうベンチに引き揚げていた。

## 伝達：3塁コーチへ

試合が始まる前に、3塁コーチを務める先輩を呼び止めた。

平野｜港南のライト、肩はミーティングで見たとおりです。
それに、高く跳ねた球でも足を止めません。
跳ね上がりに合わせて捕って、その足で投げてきます。

先輩は右翼の守備位置を見てから、
「跳ねたら一拍あると思ってた。高く跳ねても止める」と答えた。

## 共通：9回裏

港南工業は、鳳翔に走者を出しても長打を許さなかった。
6回の犠牲フライで1点は取れたが、9回裏に入っても1対2だった。

試合前のミーティングで、日和は港南のライトの映像を全員に見せていた。
3塁コーチの先輩も、鳳翔の打者が右へ打つたびに、
まずライトの足を見ていた。

1アウトから、先輩の打球が左翼線の内側に落ちた。
先輩は1塁を蹴って2塁まで行った。
次の打者が右へ打ち返すと、ベンチで誰かが「落ちるぞ！」と叫んだ。

白球がライトの前で跳ねた。2塁走者はもう3塁へ向かっていた。
ライトが前へ出て、跳ね上がった球を拾った。

## 勝利：止めた走者

3塁コーチが両手を上げた。走者はベースを踏んだところで止まった。

返球は途中の野手を越えて捕手に届いた。
走者がホームへ向かっていたら、まだ線の途中だったと思う。

1アウト1・3塁。次の打者がセンターへフライを打った。
3塁走者はベースに足を置いたまま待ち、
センターのグラブに球が入ると走り出した。
今度は返球より先にホームを踏んだ。2対2。

1塁には、右前打を打った先輩が残っていた。
大山が打席に入ると、俺は鉛筆を置いて立ち上がった。

大山の打球が左中間を抜けた。走者は2塁を蹴っても速度を落とさなかった。
3塁コーチは今度は腕を回した。

走者がホームを踏んだ。
大山は2塁で足を止め、ベンチから飛び出してくる仲間を見てから、
ゆっくりヘルメットを脱いだ。

3対2。日和が俺の肩を叩いた。
俺はまだ立ったままで、日和も座ろうとはしなかった。

## 敗退：ライトからの返球

白球が跳ね上がったのを見て、3塁コーチの先輩は腕を回した。
走者は3塁を蹴ってホームへ向かった。

返球は途中の野手を越え、捕手の胸に届いた。
捕手は球を受け、滑り込んでくる走者の腕にグラブを当てた。

球審が拳を上げた。
走者は土の上に座ったまま、返球が来たほうを振り返った。

2アウト1塁。次の打者のゴロを、港南のショートが2塁へ送った。
大山は次の打者が待つ場所で、バットを握ったままだった。

1対2。俺はスコアブックに、ホームでアウトになった走者の線を引いた。
右前に落ちた瞬間は、同点になると思っていた。

整列から戻ってきた3塁コーチの先輩が、帽子のつばを握ったまま言った。

先輩｜高く跳ねたから、捕るまで一拍あると思った。
……あいつ、跳ねた球でも足を止めねえのか。

## E2：帰りのバス

帰りのバスでは、大山は行きと同じ窓側に座っていた。
今度はカーテンが閉まっていた。膝にグラブはなかった。

通路を挟んだ窓側の席。美空は外を見ていたが、
ふと思い出したようにスマホを出し、父とのメッセージを開いた。

美空｜（甲子園には行ったんだし、レジの話はもういいよね。）

美空は「甲子園には行ったからね」と父に送り、スマホを伏せた。
窓の外に顔を向けると、ほっとしたように口元が緩んだ。

バスが高架の下を抜けた。
西日が窓から差し込み、美空の髪の縁が金色に光った。
後ろの席から身を乗り出していた先輩が、
座席の背に手をかけたまま動かなくなった。

先輩｜……笑ってくれた。俺らの前じゃ、最後まであんな顔してくれるんだな。

俺が目を開けると、先輩は手を合わせていた。
監督は窓に顔を向けたままで、こっちを見てもいなかった。

別の先輩｜明日、グラウンド使えますかね。

俺は足元の鞄を引き寄せた。
中には、今日の試合を書いたスコアブックが入っていた。
