# 5-31　取材と準備

本編初稿。甲子園2回戦、港南工業戦。勝敗を分けるのは、平野が右翼手の守備を確認し、3塁コーチに伝えられたかどうか。

## 試合前：廊下の取材

1回戦の翌日、宿の食堂を出ると、廊下の長椅子に記者が2人座っていた。俺が通ると、先に立った記者が「平野くんだね」と手帳を開いた。

記者｜昨日は最後まで、みんな監督のほうを見てたね。普段からよく声を掛けてもらうの？

ちょうど通りかかった監督が、記者の手帳を見て足を止めた。

美空｜平野くん、これお願い。先に部屋戻ってるね。

記者は俺と監督を交互に見て、「任せてもらってるんだね」と言った。監督はもう部屋の鍵を出していた。

食堂の入口から、日和がタブレットを持ってきた。港南工業の1回戦を見ていたらしい。画面には、ライトがずいぶん前で打球を拾っているところが映っていた。

日和｜向こうのライト、ここから投げてホームまで届いてる。もう1本、似た打球があったよ。

もう1人の記者も立ち上がった。先に来た人とは別の質問があるらしかった。

**選択肢：取材対応を日和と分ける／一人で取材を引き受ける**

## 事前準備：ライトの返球を見る

俺は試合の記録について答え、普段の練習については日和に代わってもらった。そのあいだに、食堂の端で映像を見直した。

1本目も2本目も、打球が落ちたときにはライトがすぐ近くまで来ていた。拾ってから足を止めずに投げ、返球は途中の野手を越えて捕手まで届いた。

平野｜右に落ちても、思ったほど時間ないな。

日和が戻ってくるまでに、どの打球で前へ出ていたか、ノートに書いておいた。

## 事前準備なし：取材に残る

俺は日和にタブレットを預け、2人の話を順に聞いた。去年の決勝のことまで聞かれて、食堂に戻ったときには、次のミーティングが始まっていた。

## 当日：面会と守備練習

試合当日。スタンド下の通路で、面会を申し込んでいた卒業生が待っていた。控えの選手を呼びに行こうとしたところで、外からボールがミットに収まる音が続けて聞こえた。港南工業の外野手が、ホームへの返球を練習している。

日和｜面会なら私が案内できるよ。外、見てくる？

**選択肢：面会の案内を日和に任せ、外野の送球を見る／面会を最後まで案内する**

## 回収：外野の送球を見る

日和に面会を頼み、グラウンドへ出た。ライトは、ほかの外野手より内野に近い位置から打球を追い始めた。前に落ちた球を拾うと、そのままホームへ投げた。

捕手はほとんど動かなかった。送球が胸の高さに届くまで、俺はライトのいた場所から目を離せなかった。

## 回収なし：面会を案内する

俺は卒業生を面会場所まで案内し、選手を連れて戻った。グラウンドへ出たときには、港南工業の外野手はもうベンチに引き揚げていた。

## 伝達：3塁コーチへ

試合が始まる前に、3塁コーチを務める先輩を呼び止めた。

平野｜港南のライト、浅く守って、前に落ちた球をそのままホームまで返してきます。右前に落ちても、思ったより時間ないです。

先輩はライトの守備位置を見てから、「分かった。打球だけで回さないようにする」と答えた。

## 共通：9回裏

港南工業は、鳳翔に走者を出しても長打を許さなかった。6回の犠牲フライで1点は取れたが、9回裏に入っても1対2だった。

1アウトから、先輩の打球が左翼線の内側に落ちた。先輩は1塁を蹴って2塁まで行った。次の打者が右へ打ち返すと、ベンチで誰かが「落ちるぞ！」と叫んだ。

白球がライトの前で跳ねた。2塁走者はもう3塁へ向かっていた。ライトが前へ出て、跳ね上がった球を拾った。

## 勝利：止めた走者

3塁コーチが両手を上げた。走者はベースを踏んだところで止まった。

返球は途中の野手を越えて捕手に届いた。走者がホームへ向かっていたら、まだ線の途中だったと思う。

1アウト1・3塁。次の打者がセンターへフライを打った。3塁走者はベースに足を置いたまま待ち、センターのグラブに球が入ると走り出した。今度は返球より先にホームを踏んだ。2対2。

1塁には、右前打を打った先輩が残っていた。大山が打席に入ると、俺は鉛筆を置いて立ち上がった。

大山の打球が左中間を抜けた。走者は2塁を蹴っても速度を落とさなかった。3塁コーチは今度は腕を回した。

走者がホームを踏んだ。大山は2塁で足を止め、ベンチから飛び出してくる仲間を見てから、ゆっくりヘルメットを脱いだ。

3対2。日和が俺の肩を叩いた。俺はまだ立ったままで、日和も座ろうとはしなかった。

## 敗退：ライトからの返球

3塁コーチが腕を回した。走者は3塁を蹴ってホームへ向かった。

返球は途中の野手を越え、捕手の胸に届いた。捕手は球を受け、滑り込んでくる走者の腕にグラブを当てた。

球審が拳を上げた。走者は土の上に座ったまま、返球が来たほうを振り返った。

2アウト1塁。次の打者のゴロを、港南のショートが2塁へ送った。大山は次の打者が待つ場所で、バットを握ったままだった。

1対2。俺はスコアブックに、ホームでアウトになった走者の線を引いた。右前に落ちた瞬間は、同点になると思っていた。

## E2：帰りのバス

帰りのバスでは、大山は行きと同じ窓側に座っていた。今度はカーテンが閉まっていた。膝にグラブはなかった。

通路を挟んだ窓側の席。美空は外を見ていたが、ふと思い出したようにスマホを出し、父とのメッセージを開いた。

美空｜（甲子園には行ったんだし、レジの話はもういいよね。）

画面には「甲子園には行ったからね」とだけ打ってあった。美空は送ると、窓のほうを向き直した。

俺が座っている列の後ろから、先輩たちの声が聞こえた。

先輩｜監督、帰りくらい寝りゃいいのに。まだ試合のこと考えてんのかな。

別の先輩｜明日、グラウンド使えますかね。

俺は閉じかけていた目を開けた。足元の鞄に、今日の試合を書いたスコアブックが入っていた。
