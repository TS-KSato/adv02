# 5-15　佐々木の指名

本編初稿。北陵戦の8回裏。鳳翔は1対2、2アウト一塁。佐々木が打席に向かうところまで。

## 本文

打席へ出かけた先輩が、バットを持ったまま通路の手前で待っていた。監督はその横を通り、球審のほうに顔を向けた。

美空｜次、バッター交代。佐々木。

立ちかけた部員が、膝に手をついた姿勢のまま止まった。バットを持っていた先輩は振り返って、ベンチのいちばん奥を見た。

ヘルメットを置き直したのは、佐々木先輩だった。今も両手をその上に置いていた。

佐々木｜……俺ですか。

監督がうなずくと、先輩はヘルメットを持ち上げた。手から滑りそうになり、あごのあたりで抱え直した。

背番号と名前を確かめながら、俺は名簿を持って廊下に出た日のことを思い出した。

追いついたとき、監督は鞄の肩ひもを直していた。俺が候補の表と名簿を並べ、名前の違う行を指すと、監督は紙に顔を寄せた。

平野｜こっち、佐々木先輩になってます。

美空｜……あ。写すとこ、ずれた。

監督は俺の手から紙を受け取った。次の瞬間、さっきと同じ折り目で畳んでいた。

平野｜提出は明日ですよ。まだ直せますけど。

美空｜めんどくさいからいいや。

今、俺の目の前で、佐々木先輩がヘルメットをかぶった。スコアブックの代打の欄に、その名前を書いた。練習のノートで何度も書いた字なのに、ここに書くと妙に見慣れなかった。

先輩｜監督、佐々木が普段どれだけやってるか、ちゃんと見てたんだな……。

隣の先輩は何も言わず、自分の膝をぎゅっとつかんだ。

佐々木先輩の肩が、小さく震えていた。うつむいていたが、口元は笑っていた。バットを握り直すと、肩の震えがすっと止まった。

北陵ベンチ。場内アナウンスで代打の名前が流れると、監督が控えの選手を呼んだ。

北陵監督｜佐々木？　打ったところ、見たことあるか。

北陵選手｜ありません。記録にも出てきません。

選手がめくった紙には、さっきまで打席にいた鳳翔の選手の名前と、打球の方向が並んでいた。

北陵監督は紙を受け取った。ここまでの継投も走者の進め方も、前の神条監督がやりそうなことばかりだった。だから試合前の資料も、現に役に立っていた。

その娘が、1点を追う8回に、そこにいない打者を出してきた。

北陵監督｜分かった。いったん、外野はそのままで。

鳳翔ベンチ。監督が俺の隣に戻ってきて、開いたスコアブックに顔を寄せた。

美空｜……あいつ、佐々木で合ってた？

声は、隣の俺が聞き返さずに済むぎりぎりだった。

平野｜……はい。

（やっぱり、顔までは分かってなかったのか……。）

佐々木先輩はもうベンチの外にいた。先に打席へ出るはずだった先輩の横を通り過ぎ、白線の手前で、一度だけこちらを振り返った。

監督は腰掛けに戻っていた。佐々木先輩はヘルメットのつばに手を添えると、顔を上げて打席へ向かった。
