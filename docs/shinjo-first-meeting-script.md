# 5-13　新庄との接触

本編初稿。5月の練習試合。大山と新庄の対戦、試合後の挨拶を描く。

## 本文

5月。帝嶺学院との練習試合で、俺は相手の打順表をスコアブックの下に敷いた。風が吹くたび、上から押さえた親指のところで紙が鳴った。

1番、センター、新庄柔斗。2年。相手ベンチから最初に名前を呼ばれた選手は、打席の土をならしながら、鳳翔のマウンドを見ていた。

大山の初球は外寄りの真っすぐだった。

ミットが鳴ってから、バットが風を切った。順番がはっきり分かるほど遅れていた。

新庄はバットを下ろした。ベンチの方から何か声が飛んだが、そちらを見ずに、もう一度同じ場所へ足を置いた。

その打席は、最後も真っすぐで空振り三振だった。

帰り際、新庄は次の打者の耳元で何か言った。次の打者がうなずくと、そのままベンチの奥まで下がっていった。

俺は最後の球の位置に丸をつけた。あれだけ振り遅れても、新庄は初球から最後まで、打席の前へも後ろへも動かなかった。

2度目の打席。新庄がまた同じ場所に立ったので、俺はさっきの丸に親指を置いた。

今度は、大山の左足が着くころには、もう新庄の前足が下りていた。バットが出たのは、そのあとだった。

外寄りの真っすぐ。短い音がして、白球が一塁手の頭を越えた。

ライトが前に出て、打球を拾った。新庄は一塁を回りかけたところで止まって、塁へ戻った。

俺が安打の線を引いているあいだ、大山はマウンドから新庄を見ていた。捕手が返した球が手に収まるまで、目を切らなかった。

試合後、大山がベンチで靴ひもを解いていると、新庄がネットの脇まで来た。

新庄｜大山くん。対戦、面白かった。ありがとう。

大山｜お前、2打席目、真っすぐだけ待ってただろ。

新庄｜うん。最後まで曲げなかったね。

大山｜次も曲げねえよ。

新庄｜じゃあ、楽しみにしてる。

新庄が帽子をかぶり直しかけたとき、奥から監督が出てきた。鞄を肩に掛け、片手には飲みかけの水を持っていた。

新庄は帽子をかぶらなかった。さっきまで大山と話していた調子で何か言いかけて、そこで口を閉じた。

監督が、通ってもいいかというように、目だけでネットの脇を見た。新庄は一歩横へよけた。

新庄｜……神条監督。帝嶺の新庄です。

美空｜はい。

新庄｜今日は、ありがとうございました。

美空｜お疲れさま。

それだけ言うと、監督は俺たちの前を通り過ぎた。新庄は下げた帽子を持ち直したが、今度も頭には戻さなかった。

少し離れたところで、監督が日和に声をかけた。

美空｜日和ちゃん。今日はもう帰っていいんだよね？

日和｜はい。鍵は私が返しておきます。

美空｜ありがとう。

日和がそう言うのを待っていたらしく、監督はそこでようやく水のふたを開けた。ひと口飲んで、今度こそ校門へ向かった。

帝嶺のベンチから「柔斗、バス出るぞ」と声がした。

新庄｜はい。……ねえ、大山くん。

大山｜なんだよ。

新庄｜神条監督は、次も来る？

大山の手の中で、ほどけかけた靴ひもがまた締まった。
