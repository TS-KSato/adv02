# 5-16　一度だけの本塁打

本編初稿。北陵戦の決着。花嫁姿の美空は佐々木の妄想。

## 本文

監督はベンチに座り直し、膝に置いた打順表を畳んだ。グラウンドでは、佐々木先輩が打席の手前で素振りをした。

バットはいつもの高さを通った。練習で見慣れた振りだった。佐々木先輩はそこで白線をまたいだ。

佐々木｜（監督……いや、美空。今まで俺を出さなかったのは、この打席のためだったんだね。）

白線の先に、白いヴェールが揺れた。花嫁姿の美空が、少し先で待っている。ベンチで見たのと同じ、小さなうなずきだった。

佐々木｜（俺がどんな男か、ここで見せる。他のやつにはできないことをやってみせる。そうしたら……俺の嫁に……。）

佐々木先輩は右足で打席の土をならした。そこに足を置くと、もうベンチには目を戻さなかった。

北陵の監督は、構えに入った佐々木を見ていた。

北陵監督｜（素振りはごく普通だった。なのに、あの構えは迷いがない。……次の球が分かってるのか？）

平野｜（向こうは何かあると思ってるのかな。佐々木先輩まで、何か分かったような顔してるけど。）

一塁ベースの脇で、大山が打席を見たままつぶやいた。

大山｜あんなやつ、うちにいたか？　……打つぞ、あいつ。

北陵一塁手｜えっ。自分とこの選手だろ？　知らないのか？

大山がリードを取った。北陵の投手は一度だけそちらを見て、捕手に向き直った。

捕手のサインに、投手はすぐうなずいた。ミットが外寄りに出る。俺が7回まで何度も「外」と書いたコースだった。今日一番よく決まっていた球で、この回を終わらせるつもりだ。

真っすぐが来た。ミットは構えた位置から動いていなかった。

その手前で、バットが鳴った。

打球はライトへ上がった。ライトが背を向けて走り出したので、俺はまだ捕れると思った。

フェンスの手前で、その足が止まった。

白球がフェンスの向こうへ消えた。ライトはグラブを上げないまま、落ちた先を見ていた。

フェンスを越えたのが分かっても、俺の鉛筆はまだ一塁のマスにあった。大山はとっくに二塁を回っていた。

大山がホームを踏んだ。同点。少し遅れて佐々木先輩が三塁を回った。さっきまで震えていた手を、小さく握ったままだった。

ホームを踏むと、ベンチの部員が一斉に先輩の名前を叫んだ。佐々木先輩は何人もの腕の間から、監督の顔を探していた。

俺は得点欄に、もう1本線を引いた。3対2。鳳翔が初めて前に出た。

向かいのベンチで、北陵の監督はフェンスから目を離し、鳳翔のベンチを見た。

北陵監督｜あそこで出すために、取っておいたのか。

監督の隣には、佐々木の名前が載っていない資料が開いたままだった。

9回表。最後の打者が打ったゴロを、中田先輩が捕った。先輩が送球したあと、一塁手のミットが鳴るまで、誰もベンチを出なかった。

一塁塁審の拳が上がった。鳳翔が3対2で勝った。

整列が終わると、スタンド下の通路にいた記者が、ノートを開いて監督のところへ来た。

記者｜あの場面で、ここまで出番のなかった選手を信じて送り出した。その理由を聞かせていただけますか。

監督が足を止めた。記者のペン先はもう紙に触れていた。

俺は少し後ろでスコアブックを閉じかけて、手を止めた。佐々木先輩の名前の横には、まだあの一打しか書いていなかった。
