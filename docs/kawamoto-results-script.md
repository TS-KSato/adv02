# 5-12　実績では伝わらない

本編初稿。「河本の証言」の両分岐から合流する。

## 本文

ベンチの奥で、鞄の口が少し開いていた。監督は練習メニューを膝に置いたまま、内ポケットのファスナーを開けたり閉めたりしていた。

河本さんが腰掛けの端まで来て立ち止まる。監督は顔を上げなかった。先輩がボールかごを置いても、グラウンドから金属バットの音がしても、河本さんはそこで待っていた。

先輩｜卒業してからも来るの、あの人くらいだよ。この前なんか、監督が帰ったって言ったら、グラウンドも見ないで帰ったぞ。

河本さんは振り返らなかった。監督がようやく鞄から手を出したところで、半歩だけ近づいた。

河本｜今年は二桁勝ちます。

監督が顔を上げた。さっきまで大山と話していたときより、河本さんの背筋が伸びた。

河本｜そのときは、また話を聞いてもらえますか。

監督の手が、鞄のファスナーをつまんだ。

美空｜……それだけか？

グラウンドでもう1本、バットが鳴った。誰かが「ショート！」と叫んだ。

河本さんは黙っていた。膝の上の新聞へ目を落として、また監督の顔を見た。

河本｜15勝します。

ファスナーが端まで滑った。

河本｜次は、その報告をしに来ます。

河本さんは返事を待たずにベンチを出た。出口でいったん歩みを緩めたが、振り返らなかった。

新聞に載っていた数字は8勝だった。あの記事が出るだけでもすごいのに、そこからあと7つ。あんな小さな声で言ったのに、河本さんがいなくなっても、俺の耳には15という数字が残っていた。

監督は閉めた鞄を持ち上げた。膝の紙がずれ、新聞の切り抜きだけが滑り落ちかけた。監督はその角をつまんで立ち上がった。

美空｜で、あいつ何しに来たんだ？

平野｜えっ!?

思わず監督の顔を見た。冗談を言った顔じゃなかった。その手には、河本さんの新聞の切り抜きがまだ挟まっていた。
