# 5-21　大山の復帰

本編初稿。夏休みの終わり。大山の再診と、平野とのキャッチボール。

## 本文

グラブを持ってグラウンドへ行くと、大山が外野のフェンス際にいた。片手で球を放り上げ、落ちてきたところを素手で取っていた。

こっちに気づくと、大山は右足から踏み出した。かばう様子もなく、土の上をまっすぐ歩いてくる。松葉杖は見当たらなかった。

平野｜半年って言ってたよね。

病院で日和から帽子を受け取ったのが、まだ1か月ほど前だった。

大山｜平野。俺はお前らみたいな凡人とは違う。それに、俺には美空の愛がある。

平野｜いや、半年っていう数字はどこいったんだよ。

大山は球を握り直した。そのまま投げるのかと思ったら、グラブもつけずに校門のほうへ歩き出した。

大山｜今日、再診だ。来いよ。どうせ俺が言っても信じねえだろ。

病院で、医者は新しい画像を出してから、前の画像を出し直した。2枚を並べ、今度は日付を見比べた。

医者｜……これ、まだ1か月か。

大山｜だから、もう治ったって言ったでしょう。

医者はすぐには返事をしなかった。右足を診て、立たせてから、もう一度画像に目を戻した。

平野｜先生、本当に大丈夫なんでしょうか。

医者｜骨はついてる。ついてるんだけどね。医者としてはちょっとした悪夢だよ。なんでこんなに早く治るの。

大山｜ふふ……美空、待っていろ。

医者｜聞いてるか。今日は軽いキャッチボールまでだぞ。

診察室を出ると、大山は廊下を走りかけた。俺が何も言わずに立ち止まると、数歩先から振り返って、歩幅を戻した。

グラウンドには、もう誰もいなかった。大山は俺から少し離れ、投げる手を上げた。

平野｜本当に軽くね。

大山｜軽くならな。雑魚相手には、それで十分だ。

大山は宣言どおり、ゆるい球を投げた。それでも胸の前に来た球がグラブに収まったとき、乾いた音がした。

返球を受けた大山が、誰もいないベンチを見た。俺は、大山の名前がなかった決勝の打順表を思い出した。

大山｜もう美空に、あんな顔させねえよ。

俺はグラブを胸の前に戻した。今度は、もう少し離れたところから投げてもらうことにした。
