# 5-5　優勝と結婚

本編初稿。「美空の登場」の続き。選択肢で、平野が大山本人と部内の噂のどちらを先に聞くかが変わる。

制作メモ：美空の「最後まで任せられる人がいい」は、練習試合の段取りを任せる係についての言葉。先輩は、結婚の噂を前提にエースのことだと受け取っている。

## 共通：片づけのあと

練習の終わりまで、スコアブックは三回のところを開いておいた。

もう一度見せろと言われるかと思ったけれど、監督は先に帰った。ページを閉じて、挟んでいた鉛筆を鞄の横のポケットに戻した。

スパイクを脱いでいた先輩たちが、なんとなく、まだベンチに残っていた。

大山がバットを片づけに来た。棚に立てかけると、帰らずに俺の前で足を止めた。

大山｜何を話した。

平野｜誰と？

大山｜美空とだよ。

俺はさっき閉じたばかりのスコアブックを見た。

平野｜三回の記録。見せてって言われて、見せた。

大山｜それで？

平野｜そこ開いといてって。それだけだけど。

大山は、俺がまだ何か言うと思っているようだった。俺も、あとは何を聞きたいのかと思って待った。

平野｜なんで？

大山｜甲子園で優勝したら、俺は美空に結婚を申し込む。

鞄の口を広げたまま、大山の顔を見た。

平野｜……結婚？　何の話？　なんでそうなるの？

大山｜ああ。

聞き間違いではなかった。三回の記録の話から、どこでそっちへ曲がったのかは分からなかった。

先輩｜待てよ。もうお前がエースになるつもりか。

ベンチの端で、先輩がスパイクの紐をほどく手を止めていた。

別の先輩｜エースとは限らねえだろ。俺は、決勝で一番活躍したやつだって聞いたぞ。

俺より先に聞き返したのは、大山だった。

大山｜何の話だ。

先輩｜甲子園で優勝したら、そのときのエースが監督の結婚相手の候補になるって話だよ。

大山｜知らねえ。俺は、俺が申し込むって言ってんだ。

別の先輩が片足だけ靴を履き替えたまま、誰かのほうを見た。見られた先輩は、何を今さら、という顔をしていた。

ここでその話を初めて聞いたのは、どうも俺と大山だけだった。

**選択肢：大山に聞く／先輩に聞く**

## A：大山に聞く

大山は、バットの向きを揃えようとしていた。自分のを手前に置き直すまで待って、声をかけた。

平野｜噂じゃないなら、いつからそう思ってたの。

大山｜中学のとき。高校野球を見に行った。

試合の話になるかと思った。大山は、どこが勝ったかは言わなかった。

大山｜鳳翔の選手が引き上げてきて、そのあとに美空がいた。スタンドからでも分かった。

平野｜誰かに、あの人が監督だって聞いたの？

大山｜それはあとで聞いた。

平野｜監督だって知らないうちから？

大山｜ああ。

それ以上の理由があるのかと待ったが、大山の中では、そこまでで十分らしかった。

平野｜じゃあ、さっきまで結婚の噂は知らなかったんだ。

大山｜噂なんか関係ねえ。俺と美空は結婚する運命なんだ。

さっき「エースになるつもりか」と言われたときより、こっちの返事のほうが早かった。

## B：先輩に聞く

先輩は、途中になっていた紐をほどき直していた。俺は声を落とした。

平野｜あの話、先輩たちはいつ知ったんですか。

先輩｜入ってから。俺も最初は知らなかったよ。

平野｜誰に聞いたんですか。

先輩｜上の代。俺も一年のとき、何でそんなにみんな張り合うんですかって聞いたんだよ。

平野｜野球のことで？

先輩｜最初はな。

片方のスパイクを脱いで、泥が落ちないよう袋の中へ入れた。

平野｜その先輩からは、エースだって聞いたんですか。

先輩｜そう。

別の先輩｜だから、俺が聞いたのは決勝で一番働いたやつ。打って決めてもいいんだよ。

平野｜どっちが本当なんですか。

先輩｜エースだよ。この前も監督が「最後まで任せられる人がいい」って言ってた。最後まで投げるやつのことだろ。

そう言って、先輩は残りの紐をほどいた。今度は途中で手が止まらなかった。

## 合流：明日の練習

鞄に手をかけたところで、スパイクを袋に入れた先輩が大山を呼んだ。

先輩｜大山。明日、投げ足りなかったら呼べ。打席に立ってやる。

大山｜左で立ってくれますか。左相手に試したい球があるんで。

先輩｜いいぞ。打っても文句言うなよ。

大山｜打てたらな。

さっき結婚相手の候補を争っていた二人が、左の打者にどんな球を試すか話しながら先に出ていった。

もう一人の先輩が、ベンチの下に転がっていた球を拾った。「大山」と呼んで、球を放った。

大山が振り返って捕った。

別の先輩｜右も要るだろ。俺も行く。

大山｜なら最初に左。あとで右。

二人ともそれでいいらしかった。返事が揃った。

ベンチに残った俺は、開けたままだった鞄にスコアブックをしまった。

来たばかりのころは、次の一本を誰が打つかであれだけ張り合うのが不思議だった。今日も、明日の練習相手がもう決まった。

ただ、今の会話のどこからが野球の話だったのか、途中で区切ろうとすると、うまくいかなかった。
