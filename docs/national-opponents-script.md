# 5-30　全国の相手

本編初稿。甲子園1回戦、星浜学園戦。鳳翔は6対2で勝利し、次の場面で2回戦の準備へ進む。

## 本文

甲子園のベンチから見上げると、外野席のいちばん上まで人がいた。日和に「平野くん、打順表」と言われて、俺は手に持っていた紙をようやく渡した。

1回表の攻撃が終わり、俺はスコアブックを守備のページに返した。グラブを取りに戻った先輩が、隣の小宮に声をかけた。

先輩｜さっき監督が「小宮」って呼んでたな。お前、何したんだよ。

小宮｜タオルがたまたま僕の足元に落ちたんです。拾って渡しただけですよ。

小宮は先輩のグラブを棚から取って渡した。先輩はまだ何か聞きたそうだったが、グラブをはめて守備に出た。

星浜学園は、立ち上がりから大山の球を打ちにきた。最初の打者が外寄りの真っすぐをファウルにすると、次は大山が同じところに投げた。今度はバットが振り遅れなかった。白球が1塁手の頭を越えた。

俺は鉛筆を持ち直した。県大会では、あのコースの球が振り遅れたバットを抜けて、そのままミットに入るところを何度も見た。

続く打者が左中間を破った。先頭打者がホームまで帰り、打った走者は2塁で止まった。田原がマウンドに来ると、大山は口元をグラブで隠して何か言った。

田原がホームに戻り、さっきより低いところにミットを構えた。

大山はマウンドの土をならし、2塁を一度だけ見てから投げた。次の打者は低い真っすぐに差し込まれ、打球は1塁側の客席に飛んだ。

星浜のベンチでは、次の打者がファウルの行方を見て、バットを握り直した。

星浜選手｜低いとこでも、あんなに伸びてくんのか。地方大会の映像よりキレてません？

別の星浜選手｜先頭が打てたから、いけるかと思ったんだけどな。

次の球も低かった。今度は土の上で跳ねた。田原は膝を落として胸で止め、前に転がった球を拾った。2塁走者は、出しかけた足を引っ込めた。

星浜監督｜捕手も見とけ。あれを後ろにそらさないから、大山も走者がいてあそこに腕を振れるんだ。

監督は、素振りを再開しようとした打者を呼び止めた。

星浜監督｜低いのまで追うな。最初の打者が打った高さを待て。

俺のスコアブックでは、1回の星浜の得点はその1点で止まった。

星浜は3回にも1点を加えた。鳳翔は4回に安打をつないで追いついた。5回表、2対2。走者を1塁に置いて、大山に打順が回った。

星浜の捕手は、初球から外に構えた。大山は外に外れた球を2球続けて見送った。3球目も外だったが、今度はストライクゾーンの端に残った。大山が踏み込んだ。打球は右中間のスタンドに入った。4対2。

ベンチに戻ってきた大山は、差し出された手を順に叩いた。俺が立ったままでいると、最後に俺の手も叩いた。

平野｜2点目取られたとき、ちょっと焦った？

大山｜なんでだよ。俺が打ちゃいいだろ。

7回表、1アウト1・2塁。小宮が右前に落とした。2塁にいたのは、朝、小宮が監督に名前を呼ばれたことを気にしていた先輩だ。

先輩は打球が落ちるのを見てから、一気に3塁を回った。ライトはホームへ投げた。滑り込んだ先輩の手が捕手のミットより先にホームに届き、その返球の間に、1塁にいた走者も3塁へ進んだ。

球審が両腕を広げた。俺も「セーフ！」と叫んでから、まだ得点を書いていないことに気づいた。

ベンチに戻った先輩は泥を払う暇もなく、1塁にいる小宮に向かって拍手した。

先輩｜小宮、いいとこ打ったな！

そう叫んだあとで、先輩は監督のほうを振り返った。

先輩｜監督、今の俺のスライディング、見てました？

監督が顔を上げたところで、次の打者の名前が流れた。打者はセンターまでフライを運び、3塁走者は捕球を見てからホームへ走った。6点目が入った。

9回裏、最後の打球はショートの前で跳ねた。小宮が前へ出て捕り、1塁へ投げた。走者の足がベースに届く前に、ミットが鳴った。

6対2。スコアブックを閉じると、俺の手には鉛筆の跡がついていた。整列に向かう先輩のユニフォームには、さっきのスライディングの泥がまだついていた。
