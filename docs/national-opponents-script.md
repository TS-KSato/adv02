# 5-30　全国の相手

本編初稿。甲子園1回戦、星浜学園戦。鳳翔は6対2で勝利し、次の場面で2回戦の準備へ進む。

## 本文

甲子園のベンチから見上げると、外野席のいちばん上まで人がいた。
日和に「平野くん、打順表」と言われて、
俺は手に持っていた紙をようやく渡した。

試合前のノックが終わり、選手がベンチの前に戻ってきた。
日和は星浜の打順表をベンチの壁に貼り、上から指でなぞった。

日和｜星浜の1番から3番、地方大会の映像だと、みんな初球から振ってた。
真っすぐを待ってるよ。ファウルでも当てたら、次は合わせてくる。

三浦｜外野は前に出るのが速いな。
さっきのノックでも、ライトが何度も前で捕ってた。

小宮｜ただ、ライトの方は、捕ったあと一度足をそろえてから投げていました。
中継に入るセカンドの方も、体を回してから送球されています。

岡田｜前で捕られても、投げるまでに一拍あるってことか。

先輩｜なら決まりだ。打ったら走れ。
2塁にいたら、ライト前で止まるなよ。

返事がそろった。
三浦は返事をしてから、ベンチの端にいる監督を見て、
帽子のつばを指でそろえた。
監督は膝の上のタオルをたたみ直していた。

1回表の攻撃が終わり、俺はスコアブックを守備のページに返した。
グラブを取りに戻った先輩が、隣の小宮に声をかけた。

先輩｜さっき監督が「小宮」って呼んでたな。お前、何したんだよ。

小宮｜タオルがたまたま僕の足元に落ちたんです。拾って渡しただけですよ。

小宮は先輩のグラブを棚から取って渡した。
先輩はまだ何か聞きたそうだったが、グラブをはめて守備に出た。

星浜学園は、立ち上がりから大山の球を打ちにきた。
最初の打者が外寄りの真っすぐをファウルにすると、
次は大山が同じところに投げた。今度はバットが振り遅れなかった。
白球が1塁手の頭を越えた。

俺は鉛筆を持ち直した。
県大会では、あのコースの球が振り遅れたバットを抜けて、
そのままミットに入るところを何度も見た。

続く打者が左中間を破った。
先頭打者がホームまで帰り、打った走者は2塁で止まった。
田原がマウンドに来ると、大山は口元をグラブで隠して何か言った。

田原がホームに戻り、さっきより低いところにミットを構えた。

大山はマウンドの土をならし、2塁を一度だけ見てから投げた。
次の打者は低い真っすぐに差し込まれ、打球は1塁側の客席に飛んだ。

1塁の先輩が、マウンドへグラブを向けた。
「ナイスボール！　その低さ！」

星浜のベンチでは、次の打者がファウルの行方を見て、バットを握り直した。

星浜選手｜低いとこでも、あんなに伸びてくんのか。地方大会の映像よりキレてません？

別の星浜選手｜先頭が打てたから、いけるかと思ったんだけどな。

次の球も低かった。今度は土の上で跳ねた。
田原は膝を落として胸で止め、前に転がった球を拾った。
2塁走者は、出しかけた足を引っ込めた。

星浜監督｜捕手も見とけ。
あれを後ろにそらさないから、大山も走者がいてあそこに腕を振れるんだ。

監督は、素振りを再開しようとした打者を呼び止めた。

星浜監督｜低いのまで追うな。最初の打者が打った高さを待て。

打者が打席へ向かったあとも、星浜の監督は鳳翔の捕手から目を離さなかった。

星浜監督｜先頭に打たれたあと、ミットを1つ下げただけだ。
大山はそこへ、次の1球目から投げてきた。
話が1回で済むバッテリーは、崩すのに手間がかかる。

別の星浜選手｜構えたとこから、ミットがほとんど動かないんですよ。
あの球を、最初に構えた場所で捕ってる。

監督は答えず、スコアブックの鳳翔の捕手の欄に、何かを書き込んだ。

俺のスコアブックでは、1回の星浜の得点はその1点で止まった。

星浜は3回にも1点を加えた。鳳翔は4回に安打をつないで追いついた。
5回表、2対2。走者を1塁に置いて、大山に打順が回った。

星浜の捕手は、初球から外に構えた。
大山は外に外れた球を2球続けて見送った。
3球目も外だったが、今度はストライクゾーンの端に残った。
大山が踏み込んだ。打球は右中間のスタンドに入った。4対2。

ベンチに戻ってきた大山は、差し出された手を順に叩いた。
俺が立ったままでいると、最後に俺の手も叩いた。

平野｜2点目取られたとき、ちょっと焦った？

大山｜なんでだよ。俺が打ちゃいいだろ。

7回表、1アウト1・2塁。小宮が右前に落とした。
2塁にいたのは、
朝、小宮が監督に名前を呼ばれたことを気にしていた先輩だ。

先輩は打球が落ちるのを見てから、一気に3塁を回った。
ライトはホームへ投げた。
滑り込んだ先輩の手が捕手のミットより先にホームに届き、
その返球の間に、1塁にいた走者も3塁へ進んだ。

球審が両腕を広げた。
俺も「セーフ！」と叫んでから、まだ得点を書いていないことに気づいた。

ベンチに戻った先輩は泥を払う暇もなく、
1塁にいる小宮に向かって拍手した。

先輩｜小宮、いいとこ打ったな！

そう叫んだあとで、先輩は監督のほうを振り返った。

先輩｜監督、今の俺のスライディング、見てました？

監督が顔を上げたところで、次の打者の名前が流れた。
打者はセンターまでフライを運び、
3塁走者は捕球を見てからホームへ走った。
6点目が入った。

9回裏、最後の打球はショートの前で跳ねた。
小宮が前へ出て捕り、1塁へ投げた。
走者の足がベースに届く前に、ミットが鳴った。

6対2。スコアブックを閉じると、俺の手には鉛筆の跡がついていた。
整列に向かう先輩のユニフォームには、
さっきのスライディングの泥がまだついていた。

その夜、宿の食堂で夕飯の皿が下げられると、日和が紙を1枚出した。
次に当たる港南工業の、地方大会からの結果だった。

日和｜港南、地方大会の準々決勝から甲子園の1回戦まで、4試合ぜんぶ1点差。
勝った試合も、1対0と2対1。

平野｜相手の安打は、毎試合7本か8本は出てるのに。

日和｜うん。走者は出させてくれる。帰してくれないの。

岡田｜ノーアウトで出たら、バントでも何でもいいから3塁まで進めたいな。
3塁なら、内野ゴロでも外野フライでも帰れる。

三浦｜外野フライで1点、っていうのも数に入れとかないとな。
1本でつなぐのを待ってたら、9回が来る。

先輩｜長打は当てにすんなってことだろ。
じゃあ、大山の前に誰か1人置いとけ。

大山｜置いとけ。帰してやる。

大山は湯のみを置いて、先に部屋へ戻っていった。
俺はスコアブックを開き直した。
今日の残塁の欄には、丸が4つ並んでいた。

塁に出た誰かが、そこで止まったまま回が終わった印だ。
書いているのは俺でも、あの塁に立っていたのは俺じゃない。
それでも、丸を1つ書くたびに腹の底が重くなった。

平野｜次は、塁に残す人を1人でも減らしたいな。

日和｜港南の映像、明日の朝までにまとめておくね。
