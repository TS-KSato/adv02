# 5-22　世代交代

本編初稿。中田たちが引退し、後輩に資料を渡す。

## 本文

3年の先輩たちが、部室の棚から私物を引き上げに来た。いつもは奥まで詰まっている棚から、予備のスパイクや着替えが出ていく。中田先輩の場所には、名前を書いたテープと、分厚いファイルが1冊残った。

俺がファイルに手を伸ばすより先に、中田先輩が取った。持って帰るのかと思ったら、机に置いて開いた。

中田｜龍成のページ、見てみろ。

試合の日付が古い順に並んでいた。俺が初めて龍成を見た日より、ずっと前の試合もあった。武藤の欄には、打った球だけでなく、どんな球を見送ったかまで書いてある。

中田先輩は、いちばん新しいページを開いた。「7回、走者1塁。初球、内寄りの直球。本塁打」。俺のスコアブックにあるのと同じ一打だった。

その下には、同じコースで打ち取った別の試合の日付も書いてあった。

中田｜内は全部だめだって覚えるなよ。打たれた日だけ見てると、そう思うからな。

中田先輩はページを閉じた。表紙には、題名より大きな字で「中田」と書いてあった。

中田｜監督に読んでもらってくれ。あと、これは中田が残したものだ。優勝した場合は、中田の功績だと監督に伝えるように。これは厳命だ。

平野｜……はい。

（うわあ、嫌な厳命。）

先輩は返事を聞くと、もう一度ファイルの表紙をこちらに向け直した。名前を見落とされる心配でもあるらしかった。

棚の下には、同じようなファイルが何冊も並んでいた。背表紙には「守備練習」や「対戦校」の文字より大きく、書いた人の名前が入っていた。どれも、表紙をめくると最初に「監督へ」とある。

守備練習のファイルを1冊開いた。うまくいった日の手順だけでなく、うまくいかなかった日に、どこで足が止まったかまで書いてあった。

（中田先輩、あの顔であんな細かい記録を残すのかと思ったけど……ほかの先輩もか。強豪校だって、ここまで残してるところはそうそうないだろ。）

そうか。だからこんなに丁寧に名前が書いてあったのか。

中田先輩が最後の荷物を持って出ていくと、日和が棚からファイルをもう1冊出した。

日和｜去年の龍成戦も出てきた。こっちは去年の棚に戻す？

平野｜龍成の分は一緒に置こう。年だけ分かるようにしとけば、すぐ見比べられる。

日和は背表紙の空いたところに、年度を書いたテープを貼った。俺は対戦校ごとに机へ並べ、今年のスコアブックをその隣に置いた。

監督に渡す分は、日和が机の端に重ねた。いちばん上の表紙から、中田先輩の名前がこちらを向いていた。
