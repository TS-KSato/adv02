# 5-17　表情が意味を持つ

本編初稿。平野が思い返す北陵戦から、準決勝前夜の神条家へ移る。神条家での会話を平野は知らない。

## 本文

北陵戦のスコアを清書していて、試合の途中で美空監督が笑ったのを思い出した。

まだ負けていた。味方が1人、凡退して戻ってきたところだった。監督は膝の上で何か指を折っていて、最後の指を折ると、口元がほんの少し緩んだ。

ちょうど北陵の捕手が、ベンチの前を通った。監督と目が合ったあと、マスクをかぶり直す手が止まった。マウンドへ戻りかけた投手を呼び止め、グラブで口元を隠して何か話していた。

その次に鳳翔が点を取られたときは、監督の眉間に深いしわが寄った。

中田｜見たか、監督の顔。1点で済ませるぞ。

誰かが「はい！」と返して、内野の声が急に大きくなった。

準決勝の前夜。神条家の居間で、美空は自分のメモを持って厳のそばに来た。

美空｜北陵に勝った分、足した？

メモには金額がいくつか並んでいて、その下に「新作ゲーム発売」と日付が書いてあった。

厳｜あ、……ああ。それはそうと、甲子園が見えてきたな。

美空｜うん。

美空｜（新作、楽しみだな～。）

美空は発売日を見て、口元を緩めた。北陵の捕手が試合中に見たのと、同じ笑みだった。

厳｜前に話した店、募集が出てたぞ。

美空は差し出された求人の紙を開きかけて、「レジ・品出し」のところで手を止めた。さっきまで笑っていた口元がこわばった。

美空｜げっ……レジもやるの？

厳｜品出しだけの募集じゃない。

美空｜でも、知らない人に、こっちから声かけるんでしょ。

厳｜ぐだぐだ言うな。店なんだから客は来る。

美空は口を開いたまま、厳を見ていた。やがて目を落とすと、折り目を合わせようとした。紙の角が何度もずれた。

美空｜……それ、無理。

厳｜いい加減にしろ。このまま何もする気がないなら、家からも追い出すぞ。

美空｜うっ……わかりました。

美空は求人を畳んで、椅子の背に掛けていた鞄にしまった。

厳が居間を出ていってから、美空はテーブルに残したゲームのメモを裏返した。
