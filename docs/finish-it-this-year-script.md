# 5-27　今年こそ終わらせる

本編初稿。夏の大会前。グラウンドから、その晩の神条家へ。

## 本文

夏の大会が近づくと、練習の終わりに、走者を置いて1打席ずつ勝負するようになった。今日は大山が投げ、小宮がショートに入った。俺はベンチの前で、走者役を待ちながら見ていた。

1塁にいた先輩がスタートを切った。打者が振り遅れて、球が田原のミットに入った。田原は立ち上がる勢いのまま2塁へ投げた。

小宮が送球を受けてグラブを下ろすと、ちょうどそこに先輩の手が滑り込んできた。

先輩｜……もうちょっとだったろ。

小宮｜もうちょっと、でしたね。

先輩は小宮のグラブを見て、それから、もう1本やらせろと立ち上がった。

去年の今ごろは、大山が投げると、その球を打てるかどうかばかり見ていた。今年は捕ったあとまで目が離せなかった。

日和がベンチからボールのカゴを引き寄せた。その横で監督が、大会の組み合わせ表を広げていた。折り目を開くと、最後の試合の日付が出てきた。

美空｜……今年こそ終わらせる。

2塁から戻ってきた先輩が足を止めた。

先輩｜聞いたか。甲子園に行くだけじゃないぞ。

大山はマウンドで、田原のほうにグラブを上げた。

大山｜当たり前だ。誰が負けて帰るかよ。

監督は組み合わせ表を畳み、日和に渡した。グラウンドでは、さっきアウトになった先輩がもう1塁に立っていた。

先輩｜小宮、さっき俺が走ったの、いつ見えた？

小宮｜投げる前に、先輩が2塁のほうへ体を向けたときです。それで早めにベースに入りました。

先輩｜そこでもうバレてたか。平野、次お前走ってみろ。リードは今と同じで、出るまで肩を開くな。

先輩｜小宮、今度も走るのが見えたら、あとでどこで分かったか教えてくれ。

小宮｜はい。田原にも、こっちがベースに入るのが遅れたら言ってもらいます。

先輩が1塁を空けた。俺はベースからさっきの先輩と同じくらい離れ、小宮が守備位置に戻るのを待った。

その晩、神条家の居間。厳はテーブルに、昨夏の龍成戦の記録と、春からの練習試合の記録を並べていた。古いほうの表紙には「中田」と大きく書いてある。

武藤が本塁打にした内寄りの直球。その記録の横に、厳は今年の練習試合で田原が受けた球のコースを書き出していた。

美空が飲み物を取りに来て、テーブルの端から紙をのぞいた。

美空｜それ、明日の分？

厳｜そうだ。明日は走者を置いたところから始めろ。去年は最後まで、そこを詰めきれなかった。

美空｜じゃ、できたら置いといて。

厳｜おい、どうして走者を置くのか、分かってるのか？

美空｜……それも書いといて。

美空が冷蔵庫を閉めて出ていくと、厳はノートを開いた。春の試合の記録には、田原が走者を2塁で刺した回と、小宮の返球で走者を3塁に進ませなかった回があった。

厳｜大山の球は、プロに混ぜても通用するだろうな。だが、あの球を受けてすぐ2塁に投げられる捕手が、1年で入ってくるとはな。

厳は小宮の中継が記された行を読み返した。アウトにはなっていない。それでも、次の打者に回ったとき、走者は3塁ではなく2塁にいた。

厳｜小宮も、返す先を捕る前に決めてる。あの2人、もう夏に使えるな。

厳は新しい紙を取り、先に田原と小宮の名前を書いた。
