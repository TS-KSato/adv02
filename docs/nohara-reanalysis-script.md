# 5-28　野原の再分析

本編初稿。2年目の夏。龍成の部室で、野原が鳳翔の試合を見返す。平野はこの場面にいない。

## 本文

龍成の部室では、窓の外が暗くなっても、テレビの明かりがついていた。野原はリモコンを手に、去年の決勝を見返していた。画面には、まだ2対2の掲示板が映っている。

鳳翔の内野が前へ出たところで映像を止めた。机の上にあった古いノートを開く。同じように内野が前へ出た場面に、日付が2つ書いてあった。どちらも厳がまだ鳳翔の監督だった年だ。

野原｜ここで1点をやらない。神条さんなら、そうするよな。

去年はそうやって、知っている相手と試合をするつもりで準備した。大山が出ないと分かってからは、打つ球も絞れた。終わってみれば4対2。その準備で取れた点は、確かにあった。

部室の戸が開いて、選手が春の練習試合の映像を入れたタブレットを持ってきた。

龍成選手｜監督、頼まれてた映像です。佐々木のヒットから出しますか？

野原｜凡退した打席もあるか。

龍成選手｜あります。そっちも見ますか？

野原｜そっちからだ。

映像では、佐々木が外の球を打って、セカンドの前にゴロを転がした。別の試合では、同じような球を打ち上げた。野原はどちらも、打ったあとに佐々木がベンチへ戻るところまで見た。

次に、去年の北陵戦を再生した。8回裏、2アウト。佐々木が打席に入る。野原はバットが球に当たるところで止めた。

野原｜北陵の投手も、投げ損なっちゃいないんだよな。

選手はテレビの前に立ったまま、答えなかった。映像を少し戻すと、打席へ向かう佐々木の後ろに、ベンチへ引き返す美空が小さく映っていた。

野原は巻き戻した。もう一度、佐々木が出てくるところから見た。

野原｜打った理由なら、あとから何とでも言える。あの場面で、なんでこいつを出したんだ。

選手が帰ったあと、野原は今年の鳳翔の試合を開いた。走者が1塁に出ると、打者はバントの構えをした。大山は初球からストライクを取った。ノートには去年の決勝の続きではなく、今年の大山の投球を1球目から書いた。

ノートを閉じる前に、北陵戦をもう一度開いた。映像を止めたのは、本塁打のところより少し前。美空が打順表を膝に置き、立ち上がったところだった。
