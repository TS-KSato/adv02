# 章間　夏の名簿

本編初稿。「新庄との接触」と「地方予選」の間に入る。

## 本文

夏の組み合わせが決まった日、日和は部室の壁から練習予定表を外した。四隅の画びょうを抜くと、紙の下だけ壁の色が白かった。

代わりに貼った紙には、県内の高校の名前が小さな字で並んでいた。日和が最後の画びょうを押し込む前に、背後から大山の腕が伸びてきた。

大山｜何回勝てば甲子園だ。

日和｜待って。まだ貼れてない。

大山は指を引っ込めた。日和が手を離した途端、今度は紙の真ん中を指で押さえた。

平野｜そこは決勝。うちはこっちから。

俺が端にある鳳翔の名前を示すと、大山はそこから試合ごとの線をなぞった。途中で相手の校名に指がかかっても、止まらなかった。

大山｜分かった。全部だ。

そこまで数えたんじゃなかったのか。聞こうとしたときには、もう大山はグラブを取って戸口にいた。

練習が始まると、佐々木先輩が打撃ケージの後ろに入った。中田先輩が打つたび、ネットの下からこぼれてくる球を拾っては、かごに戻していた。

片づけのあとも、先輩はネットの裾を持ち上げていた。最後の1球が隅に残っていたらしい。

佐々木｜平野、カゴはまだあるか？

俺が差し出すと、先輩はそこへ球を落とした。空のかごの底で、思ったより大きな音がした。

帰り支度をしていると、監督が部室の戸を少しだけ開けた。隙間から、折り目のついた紙を差し入れた。

美空｜平野くん。大会の名簿。スコアに使うなら、控え取っといて。

受け取った紙を机に広げた。俺のスコアブックには、春から試合に出た選手の名前が、相手校ごとに何度も出てくる。名簿の上から順に見ていくと、どれも書き慣れた名前だった。

控えの欄まで来て、指が止まった。練習のノートには書く。試合のページでは、代打の欄にもまだ書いた覚えがない。

「佐々木」。

廊下で監督の足音が遠ざかっていく。俺は紙を持って、戸口まで出た。
