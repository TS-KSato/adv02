# 章間　空いた一行

本編初稿。龍成戦のあとの部室から、夏休みの終わりへ。

## 本文

学校へ戻ると、先輩たちは使った道具を棚に戻して帰っていった。最後の1人が戸を引くまで、誰も次の試合の話をしなかった。

日和が空のボトルを片づける横で、俺は机にスコアブックを開いた。9回裏の終わりまで、走者がどこまで進んだかも、誰が打ったかも書いてある。最後の打球を捕ったのがライトだということも、覚えていた。

「右飛」と書けば済む。清峰戦で大山が倒れたときに書いたのと同じ、たった2文字だ。

鉛筆を持ったまま、もう一度、9回裏の頭から読み直した。書き直すところはどこにもなかった。

日和が、机の向かいでボトルのふたを閉めた。

日和｜それ、持って帰る？

平野｜うん。あとで書く。

日和はそれ以上聞かなかった。俺がスコアブックを閉じるあいだに、残っていたボトルを全部、かごにしまった。

帰り際、戸を閉める前に壁を見た。夏の組み合わせ表が、まだ4隅を画びょうで留められていた。鳳翔から決勝までの線は、大山が指でたどったときと変わらなかった。

スコアブックは、空いた一行ごと鞄に入れた。

夏休みが終わる少し前、机に置いたスマホが鳴った。画面には大山の名前と、短いメッセージが出ていた。

大山｜グラブ持ってこい。

何をするつもりか聞きかけて、やめた。グラブをしまった場所なら、まだ覚えていた。
