# 章間　最後のアウト

本編初稿。帝嶺学院との決勝、勝利側。1塁の判定から、平野がスコアブックに目を落とすまで。

## 本文

伸びきった1塁手のミットが閉じた。新庄はベースを駆け抜け、2歩目で肩越しに塁審を見た。

俺も塁審を見ていた。ボールがミットに入る音は、スタンドの声にかき消されていた。隣の日和が何か言った。口が動いたのは見えたが、聞き取れなかった。

塁審の右の拳が上がった。

小宮はまだ土の上に片膝をついていた。1塁手がミットを高く掲げると、小宮もようやく立ち上がった。

日和が俺の袖をつかんだ。今度は俺も日和を見た。何か言おうとしたが、口を開けたまま、声が出なかった。

膝の上に、スコアブックが開いたままになっていた。9回裏の新庄の欄だけが空いていた。
