# 章間　新聞と記録

本編初稿。「一度だけの本塁打」の翌朝。

## 本文

翌朝、部室の机に新聞が広げてあった。県大会の記事の真ん中に、「名将の一手」と太い字が踊っていた。

写真には、ホームを踏んだ佐々木先輩と、ベンチからせり出した部員たちが写っていた。先輩は歓声のほうを見ていない。伸びてくる腕の向こうに目をやっていた。

あのとき、監督を探していた顔だ。写真だけ見ると、次の試合を見据えているようにも見えた。

記事には、控え選手の日々の努力を見てきた神条監督が、勝負どころでその力を信じた、とあった。佐々木先輩の名前を名簿のどこで見つけたか、俺はまだ覚えていた。

大山｜おい、俺の打席は何行だ。

大山が向かいから紙をのぞき込んだ。俺は記事の終わり近くを指で押さえた。

平野｜2行。2アウトからセンター前。

大山｜佐々木は？

平野｜佐々木先輩ね。写真付きだね。

大山｜くっ……。

大山は新聞を自分のほうへ引いた。2行を確かめてから、写真が内側になるように折った。

大山｜次の相手の映像、もうあるんだろ。

平野｜あるよ。向こうの部屋で先輩たちが見てる。

大山は新聞を置いて部室を出た。廊下の向こうで、再生を少し戻してくれという声が聞こえた。

俺は昨日のスコアブックを開いた。一塁に大山がいなければ、佐々木先輩が柵越えを打っても同点だった。大山のマスから佐々木先輩のマスまで、鉛筆の線を目でたどった。

新聞を机の端に寄せ、次の試合のページを開いた。
