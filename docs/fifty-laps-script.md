# 5-7　外周50周

本編初稿。「指導の出所」の直後。美空の手が平野の口を塞いだところから続く。

## 本文

美空｜その話、ここでするな。

さっきまでグラウンドに届いていた声が、急に俺にしか聞こえない大きさになった。

返事をしようとして、口を塞がれていることを思い出した。うなずくと、監督も手を離しかけた。

そのとき、給水台のほうで、地面にボトルを置く音がした。

中田｜1年！

監督がぱっと手を引いた。給水台から、中田先輩が土を蹴って、闘牛みたいに突っ込んできた。

俺はとっさに半歩下がった。

俺の前まで来ても、先輩はすぐには俺を見なかった。まず監督の顔を見て、それから、2人のあいだに立った。

中田｜監督に何をした！

平野｜俺は何も。ちょっと、さっきの練習のことで――

さっきの話はここでするなと言われたばかりだった。監督を見ると、今度は手を出さず、目だけでこっちを見ていた。

中田｜なんで監督の顔を見るんだ。

平野｜いや、話していいかと思って。

中田｜外周50周！

平野｜ごじゅ……。

どこから出てきた数なのか聞こうとした。でも中田先輩はもう、俺ではなく監督のほうを向いていた。

美空｜そ、そうだ。よく言った。ええと……2年！

中田｜3年の中田であります！　ありがとうございます！

中田先輩は背筋を伸ばした。さっき「監督に何をした」と言ったときより、よほどいい声だった。

給水台にいた先輩が、地面に置いたボトルを拾い上げた。別の先輩が俺のほうを見たが、こっちへ来る気配はなかった。

中田先輩が振り返った。背筋は伸びたままで、眉間にだけ、またしわが寄った。

中田｜何してる。行け。

スコアブックをベンチに置いて、帽子をかぶり直した。

外周に出る門は、練習の最初にいつも走るときと同じ場所にあった。あそこを出て、校舎の裏を回って戻ってきて、やっと1周だ。

とりあえず門まで行ってから、どうするか考えることにした。

美空｜1年。戻って。

あと数歩で門に着くところだった。振り向くと、監督がベンチの前で手招きしていた。

俺の近くには、もう1人1年がいた。あいつも足を止めた。

美空｜そっちじゃない。記録つけてたほう。

俺が自分を指すと、監督はうなずいた。

美空｜さっきの話。続きがある。

引き返した。中田先輩の横を通るときに少し歩幅を狭めたが、もう「行け」とも「走れ」とも言われなかった。

ベンチでスコアブックを拾い、念のため振り返った。

中田先輩は、まだ同じところに立っていた。帽子を直している途中の手まで止まっていて、目だけがこっちを向いていた。
