# 5-10　河本の来校

本編初稿。「日和との日常」に続く。河本の来校から、美空の就任初日の話を持ち出すところまで。

## 本文

その週の放課後、練習が終わってから、俺はベンチの前で球を拾っていた。最後の1球が腰掛けの下に入って、手を伸ばしても指先にしか当たらない。

かごを持っていた先輩に、少しこっちへ来てくれませんか、と頼んだ。返事がなかった。

先輩は、グラウンドの入口を見たまま立っていた。

先輩｜河本さんだ。

茶色のチェックの上着を着た男が、入口のところで誰かに手を上げていた。白いシャツの襟元にサングラスを掛けていて、ここに用がある人には見えなかった。

顔を見て、俺にも分かった。鳳翔の元エースで、今はプロで投げている河本由伸だ。

部室に飾ってある甲子園の写真では、まだ鳳翔の帽子をかぶっていた。その顔を見慣れていたせいで、ベンチの前まで来たのを見ても、一瞬、監督が来たときみたいに整列しそうになった。

かごが足元に置かれた。先輩たちが次々に頭を下げた。俺も腰掛けの下から手を抜いて立った。

近くまで来た河本さんは、俺たちにも軽く頭を下げてから、ベンチの奥を見た。

美空｜河本。久しぶり。

監督は、練習メニューを揃えている途中だった。顔を上げたのは少しのあいだで、すぐ紙の角を合わせ直した。

河本さんは、上着の内側から折った新聞を出した。

河本｜美空……監督。去年、一軍で8つ勝ちました。

切り抜きを開くと、マウンドで帽子を取る河本さんの写真があった。折り目が、ちょうど写真の外を通っていた。

監督に見せるために開いたその紙を、隣の先輩まで首を伸ばして見ていた。

写真の下に、対戦相手の名前が見えた。俺でも知っている球団だ。そこを相手に勝った人が、いま監督の目の高さまで新聞を持ち上げ、返事を待っていた。

美空｜そう。おめでとう。

監督は写真を一度見て、練習メニューの下に挟んだ。

河本｜ありがとうございます。

河本さんは深々と頭を下げた。顔を上げたときには、新聞を出す前より嬉しそうだった。

俺の後ろで、拾った球がかごの底に落ちる音がした。振り向くと、大山が空いた手をズボンで拭いていた。

河本さんが手を引いて、写真は練習メニューにすっかり隠れた。隣の先輩はようやく目を離した。大山が見ていたのは、新聞じゃなくて監督だった。

大山｜み、美空。そいつ、誰だよ！

河本さんが顔を向けた。監督はまだ、紙を揃えていた。

河本｜……お前、今「美空」って呼んだか？

大山｜誰だって聞いてんだ。

河本｜鳳翔の元エース、河本だ。

大山｜元か。じゃあもう部員じゃねえだろ。帰れ！

さっきまで頭を下げていた先輩が、かごを持ち直した。持ち上げたのに、どこへ運ぶでもなかった。

河本｜お前な……！

河本さんは大山の前まで来た。大山はその場を動かず、返事を待っていた。

河本さんは言いかけたことをやめ、一度、監督のほうを見た。

河本｜この人が監督になった日、最初に目標を聞いたのは俺だぞ。

そこだけ、8勝を報告したときより声が大きかった。
