# 5-10　河本の来校

本編初稿。「日和との日常」に続く。河本の来校から、美空の就任初日の話を持ち出すところまで。

## 本文

練習が終わって、俺はベンチの下に転がった球を拾っていた。あと1球、腰掛けの脚に引っかかっている。

グラウンドの入口に男が立っていた。茶色のチェックの上着で、シャツの襟にサングラスを掛けている。すぐそばを部員が通ったのに、声をかけず、ベンチの奥まで見回していた。

先輩｜……河本じゃねえか。

俺も部室の写真で顔を知っていた。鳳翔の元エースで、今はプロで投げている河本由伸だ。

河本さんの目が、練習メニューを片づけていた監督のところで止まった。

別の先輩｜プロになってまで、会いに来るのかよ。

かごを持った先輩がベンチの前で足を止めた。河本さんはその横を通って、監督のところへ行った。

監督は机の端で紙の角を揃えていた。河本さんが隣に立っても顔を上げなかった。

河本｜美空……監督。

そこでようやく、監督が紙を持ったまま振り向いた。

河本さんは上着の内側から新聞の切り抜きを出した。開く前に、折り目を親指でなぞった。

河本｜去年、一軍で8つ勝ちました。

マウンドに立つ河本さんの写真が載っていた。折り目は、写真の外を通っていた。

監督は切り抜きが自分に向いているのを見て、受け取った。

美空｜そう。おめでとう。

切り抜きは練習メニューのいちばん下に入った。紙の束の角をまた揃える。

河本さんは口元を緩めた。まだ帰らず、監督がもう一度こっちを向くのを待っていた。

河本｜俺がここにいたときは――

美空｜……誰だっけ。

河本さんの口が開いたまま止まった。

ベンチの下の球がやっと取れた。立ち上がると、俺の後ろに大山が来ていた。河本さんと監督のあいだに、横から顔を出した。

大山｜み、美空。そいつ、誰だよ！

河本｜……お前、今「美空」って呼んだか？

大山｜誰だって聞いてんだ。

河本さんは大山を見た。次の言葉だけは、美空にも届くような声だった。

河本｜鳳翔の元エース、河本だ。

大山｜元か。じゃあもう部員じゃねえだろ。帰れ！

監督は紙の束を持ち上げた。河本さんの名前を聞いても、写真を見直すことはなかった。

河本｜お前な……！

河本さんが大山の正面に回った。かごを持ったままの先輩が、場所を空けるように足をずらした。止めに入るつもりはなさそうだった。

河本さんは言いかけたことをやめ、監督を一度見た。それから、大山に向き直った。

河本｜この人が監督になった日、最初に目標を聞いたのは俺だぞ。

8勝を報告したときより、声が大きかった。
