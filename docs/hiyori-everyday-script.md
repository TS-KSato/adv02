# 幕間「机の端」／5-9「日和との日常」

本編初稿。日和と選手の間には感謝と信頼がある。美空との短い会話では、日和が父の関与を知っていることには触れない。

## 幕間：机の端

監督に頼まれた紙を抱えて部室に戻ると、日和が机の端にあったテープと空き箱をどけてくれた。

日和｜平野君のは、こっちでいい？

いつも俺がスコアブックを開くところだった。今日は、そこにだけ乾いたタオルが敷いてある。

紙を置いてから、袖で机を拭かずに済んだことに気づいた。

平野｜これ、いつから敷いてくれてたの？

日和｜平野君が、机を拭いてから書いてた日から。

いつのことだろう。自分でも覚えていない。

## 共通：片づけ

別の日の練習帰り。フェンスの影がベンチの中まで伸びていた。ボールの音がしなくなると、道路を走る自転車の音まで聞こえた。

日和はベンチの前で、クーラーボックスの取っ手に用具かごを引っかけようとしていた。片方を持ち上げるたびに、もう片方が傾く。

平野｜どっちか持とうか。

日和｜助かる。両方いけると思ったんだけど。

かごの底でテープの芯が転がった。日和はそっちを押さえながら、クーラーボックスのふたも、きちんと閉まっているか確かめた。

**選択肢：飲み物を運ぶ／用具の片づけを手伝う**

## A：飲み物を運ぶ

クーラーボックスを持つと、思ったより軽かった。日和が「あ、まだ閉めないで」と言ったので、いったんベンチに置いた。

日和は冷えた小さな紙パックを取り出した。いちご牛乳だった。パックの角についた水をタオルで拭いてから、シューズの紐を結んでいた佐々木先輩に差し出した。

日和｜佐々木先輩。これ、好きでしたよね。

佐々木先輩は紐を片方だけ引いたまま、紙パックと日和の顔を順に見た。

佐々木｜……覚えてたの？

日和｜練習が終わると、いつもそれ買ってるから。

先輩は両手で受け取った。濡れてもいない紙パックを一度だけ袖で拭いて、嬉しそうに笑った。

佐々木｜ありがと。今日ちょうど買ってなかったんだ。

日和｜よかった。

俺が取っ手を持ったままだと、二人ともちょっとこっちを気にする気がした。クーラーボックスのふたを音がしないように閉めて、先に部室へ運んだ。

## B：用具の片づけを手伝う

用具かごを持ち上げると、取っ手を通してバットの重みが手にかかった。棚まで運ぼうとしたところで、日和が中から1本抜いた。

日和｜それだけ手前に置いといて。佐々木先輩、グリップ巻き直すって言ってたから。

見ると、グリップの端が少し浮いていた。上から押すといったん収まるが、指を離すとまためくれた。

佐々木先輩が戻ってきて、俺の持っているかごをのぞいた。

佐々木｜あれ、俺のバットもうしまった？

日和｜手前に出してあります。テープも、いつもの幅のが棚にありますよ。

佐々木｜助かる。明日の朝、一番に使いたかったんだ。

佐々木先輩は棚へ向かった。途中で立ち止まり、日和のほうを振り返ってもう一度「ありがとな」と言った。

日和はうなずいて、クーラーボックスからいちご牛乳を取り出した。先輩が棚に向かう前に、それも手渡した。

## 合流：翌日の片づけ

翌日、練習帰りに自販機の前を通ると、佐々木先輩が昨日と同じいちご牛乳を買っていた。

平野｜先輩、ほんとにそれ好きなんですね。

佐々木｜前に監督が飲んでたんだよ。そんなにうまいのかと思って買ったら、うまかった。

先輩はストローを差して一口飲んだ。

佐々木｜あ、日和に会ったら、今日はもう買ったって言っといてくれ。昨日もらったばっかりだから。

部室に戻って伝えると、日和は空になったクーラーボックスの中を拭きながら、「うん。分かった」と答えた。ふたを開けたまま棚の下へ置き、乾かすために少し手前へ引き出した。

俺が机のタオルを畳んでいると、部室の戸から監督が顔を出した。誰かに用があるのかと思ったら、俺のほうには特に何も言わず、日和の隣に座った。

美空｜日和ちゃん、これ半分あげる。

菓子の袋の口を広げ、日和のほうへ向ける。

日和｜ありがとうございます。じゃあ、食べたら帰りますね。

日和がひとつ取ると、監督もひとつ取った。食べる前に、もう一度日和を見た。

美空｜……もうちょっといてくれない？

日和は肩にかけかけていた鞄を、椅子の下に置いた。

俺は畳んだタオルを机の端に置いて部室を出た。戸が閉まるまで、後ろから話し声はしなかった。
