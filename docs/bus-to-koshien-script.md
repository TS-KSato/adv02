# 章間　行きのバス

本編初稿。龍成戦の勝利側。甲子園へ向かうバスの車内。

## 本文

甲子園へ向かう朝、校門の前にバスが停まっていた。大きな用具は先輩たちが車体の下へ積み込んでいた。日和は入口に立って、一人乗るたびに名簿に印をつけた。

俺が乗り込むと、大山が窓側の席にいた。通路側に置いていた自分の鞄をどけたので、俺はその隣に座った。

バスが走り出してしばらくすると、後ろの席から寝息が聞こえてきた。大山は窓の外を見ていた。景色が防音壁ばかりになっても、シートに頭を預けなかった。

平野｜寝ないの？

大山｜着くとこ見たい。

大山はこっちを向かずに答えた。膝の上にはグラブがあった。棚に上げるつもりはなさそうだった。

通路を挟んだ席では、監督が窓のカーテンを閉めていた。日和が通りかかると、監督は声を落として呼び止めた。

美空｜日和ちゃん、あと何分？

日和｜さっき聞いてから、まだ5分しか経ってないですよ。

美空｜……そっか。

監督はカーテンを指2本ぶんだけ開けた。外はまだ防音壁だった。すぐに閉めた。

前の席の先輩が、寝返りを打つように身じろぎした。足元のバッグから、帽子のつばがのぞいていた。俺の帽子も、鞄のいちばん上に入れてある。

バスが高速を降りると、窓の外を歩く人の中に、応援用のメガホンを持った人が混じり始めた。大山が少し前に身を乗り出した。俺も、その肩越しに外を見た。

平野｜……ほんとに来たんだな。

大山は何も言わなかった。窓の外を見たまま、膝の上のグラブを一度だけ握り直した。
