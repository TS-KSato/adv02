# 5-2　練習へ交ざる

確認用の本編初稿。地の文は平野の一人称。冒頭の「春のグラウンド」23行に続く。分岐は見える練習の違いで、勝敗には影響しない。

## 共通：放課後

朝のフェンスを離れてから、何度か窓の外を見た。

教室から見えるのはグラウンドの端だけだった。昼休みには、白いベースを抱えた先輩が、そこを横切った。

あの人も朝からいたんだろうか。

放課後、机の横に掛けていた袋からグラブを出した。荷造りのとき、これだけは段ボールに入れず、手で持ってきた。

紐を締め直す。握って開く。中学のときから使っているので、指を入れるだけで親指の腹がいつもの場所に落ち着いた。

制服から練習着に着替え、朝とは反対側の門から入った。振り返ると、朝立っていたフェンスの前を、まだ下校途中の生徒が通っていた。

そっち側から見ていたときは、球の音のほうが声よりよく聞こえた。中へ入ると、捕る前にも、捕ってからにも、声があった。

「一つ」「こっち」「もう一つ」。どの声にも、返事の代わりみたいに球が戻っていく。

先輩｜そこの一年。グラブ持ってるなら、入っていいぞ。

振り向くと、帽子のつばから汗が落ちそうな先輩が、底が見えるほど球の少ないかごを片手で提げていた。

平野｜いいんですか。まだ、見学だけかと思ってました。

先輩｜見ててもいいけど、持ってきたんだろ。

先輩は俺のグラブを見て言った。それから、かごの底に残っていた一球を拾って、遠くの選手に放った。

投げた先のやつが片手で受ける。かごを持ったまま投げた球なのに、相手は靴一足ぶんも動かなかった。

俺もあれくらいなら投げられる、と思ってから、かごを提げたままやったことはないな、と思い直した。

内野ではノック。外野では、打球を捕って中継へ返す練習をしている。どちらも列の最後に、一人入れるくらいの間があった。

まだ来たばかりだ。いきなり自分に向いた場所を決めなくてもいい。まず一本、球に触りたかった。

**選択肢：内野のノックに混じる／外野の返球に混じる**

## A：内野のノックに混じる

内野の列に並ぶと、前の先輩が足元を指さした。

先輩｜そこ、投げるやつが通るから、半歩だけこっち。

半歩ずれると、ちょうど俺のいたところを、捕り終えた選手が走り抜けた。グラブを叩いていた手が、もう次の球を受ける形になっていた。

最初の一本は、正面より少し右に来た。二歩寄って腰を落とす。二つ目のバウンドが手前で浮いたので、そこへグラブを合わせた。

土が手首に当たった。球はちゃんと中にあった。

一塁へ投げる。低くも高くもない。先輩は胸の前で捕って、球をかごのほうへ返した。

打った先輩が、次の球を取りながら言った。

先輩｜よし！　普通だ！

平野｜それ、褒めてるんですか？

先輩｜ああ。今の球なら、それでいい。

先輩はこっちを見もせず、次の打球を打った。

嫌味なら、もう少しこっちの反応を待つと思う。たぶん本当に、今の球ならそれでよかったのだ。

次の一年は、俺より外へ動かされた。追いついて逆手で捕り、立て直してから投げた。先輩は同じように受けた。

一年生｜もう一本。今のより右、お願いします。

先輩｜届かなくなるぞ。

一年生｜はい。届かなかったら、もう一本お願いします。

先輩は少し考えて、さっきより右へ打った。そいつは今度は触れず、打球が外野のほうまで抜けた。

拾いに走りながら、そいつはもう「もう一本」と言っていた。

自分の番が飛ばされそうなので、俺もつられて声を出した。

平野｜その次、お願いします。

先輩｜おう。お前は普通のな。

それは別に頼んでいない。でも順番が回ってくるなら、まあいい。

## B：外野の返球に混じる

外野の列に並ぶと、中継の先輩が背中を向けたまま、片手を上げた。

先輩｜捕る前に一回、俺がどこにいるか見とけよ。

言い終わるころには、先輩はもう少し右へ移っていた。投げる前に探していたら間に合わない、ということらしい。

俺の番には、浅いフライが上がった。前へ出れば間に合う。球が落ちてくるあいだに、一度だけ内野を見た。

先輩の手がまだ上がっていた。走りながら捕り、二歩で体を起こして、そこへ返した。

先輩はその場で捕った。足を入れ替えて、本塁へ投げた。

本塁でミットが鳴るより先に、外野にいた別の先輩の声がした。

先輩｜よし！　普通だ！

平野｜それ、褒めてるんですか？

先輩｜ああ。今の球なら、それでいい。

普通、と言われたときより、ボールが向こうへ渡った音を聞いたときのほうが嬉しかった。まあ、怒られていないならいい。

次の一年には、俺のときより深い打球が上がった。背中を向けて追い、落ちるぎりぎりで捕った。

返球がそれて、中継の先輩が二歩動いた。そいつはグラブを外しかけてから、思い直したみたいにまたはめた。

一年生｜もう一本。今のより奥へ、お願いします。

先輩｜先に今のをまっすぐ返せ。

一年生｜じゃあ奥から、まっすぐ返します。

無茶を言っているような声ではなかった。先輩も打ち直した。今度は捕れず、球がフェンスの下まで転がった。

球を拾いに行ったやつが戻るまで待つつもりでいたら、中継の先輩がまた俺に手を上げた。

先輩｜待たなくていい。お前、次いけ。

さっき見たときと、手を上げている場所が違った。俺はもう一度、そっちを見てから構えた。

## 合流：帰るまで

ひと通り終わったところで、先輩が「水」と言った。

給水台で、俺はグラブを脇に挟んでボトルを開けた。土のついた手では、ふたがなかなか回らない。

隣に、さっき自分から難しい球を頼んだ一年が来た。あいつもふたを開け損ねて、シャツの裾で手を拭いていた。

一年生｜明日も来る？

平野｜うん。来るよ。

一年生｜じゃあ、今度、俺の返した球も見てて。ちょっと曲がるんだよな。

平野｜いいけど。俺で分かるかな。

一年生｜外から見て、曲がってたら曲がってたって言って。

それならできる。そう言うと、そいつは水を飲み終わり、ふたを閉めて列へ戻った。

俺はもう一口飲んだ。給水台にはまだ一年が何人も残っていた。誰かが呼んだわけでもないのに、一人ずつ、同じほうへ戻っていく。

俺もボトルを置いた。グラブをはめた指が少し汗ばんでいた。さっき捕れた球ならもう一度捕れる。違う球が来たら、今度はそっちを捕ってみたい。

日が傾いて、球拾いが始まった。朝はフェンスの外から見ていた場所を、今度は内側から歩いた。

隅の草のところに一球残っていた。手で拾うと、縫い目に湿った土が詰まっていた。

先輩｜一年、帰る前にそれだけ入れといて。

かごまで球を持っていくと、さっき俺に「普通だ」と言った先輩が手を出した。

先輩｜明日もグラブ、持ってこいよ。

平野｜はい。

駅までの道で、袋の中のグラブが歩くたびに膝に当たった。

明日は最初から並べる。今は、それがちょっと楽しみだった。
