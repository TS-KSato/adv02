# 一枚絵の配置

`game.js` の `assets.cgs` と `cues`（`cg`）で指定している一枚絵の記録です。現在の一枚絵は3枚で、CG 鑑賞の対象もこの3枚です。

## 方針

- 一枚絵の ID はファイル名（拡張子なし）と同じにし、画像を差し替えても ID とファイル名は変えない。
- 置き場所は `assets/cg/`。1920×1080 の不透明 WebP を、再圧縮・描き足し・左右反転せずに置く。
- CG 鑑賞の題名は場面名にし、「妄想」「イメージ」などの説明は画面に出さない。
- 一枚絵の区間では、通常の立ち絵を重ねない。区間の次の行で、その行の背景と立ち絵に戻す。
- 本文にない出来事や具体的な想像を、一枚絵の側で足さない。本文と接続している場面だけに置く。
- 管理 ID（Magnific ID）は、公開フォルダにも、この記録にも書かない。

## 保存の移行（データ版 2026.11-5）

行 `c10-015-p1` を削除したので、データ版を 2026.11-4 から 2026.11-5 に上げた（作品ID・保存キーは変えない）。

- キットの行の対応表は、書いてある行IDだけを写す。`game.js` の末尾で、現在のすべての行を同じIDへ写し、削除した `c10-015-p1` だけを次の実在の行 `c10-016` へ写す対応表を作り、2026.11-4 と従来の各版（2026.10-1・2026.11-1〜11-3）の移行に使う。フラグの移し方は各版のまま。
- 自動・手動セーブの位置と選択（フラグ）は保つ。削除した一枚絵の区間（`c13-021`・`c26a-008`・`c26b-008` など）の保存は、同じ行から通常画面で再開する。
- 既読は、残る行の分を保つ。削除した行の既読は捨てる。
- CG 鑑賞の解放は、キットの読み込みの規則で、登録のない ID（削除した4枚）を読み捨てる。残す3枚の解放はそのまま。セーブデータの削除をお願いする必要はない。

## 表示サイズと本文枠（`game.css`）

一枚絵は、キットの既定どおりゲームの表示領域全体に敷く（`object-fit: cover`、縦横比は維持）。画像を縮小して本文枠の上に収めたり、画像の下に本文枠用の余白を取ったりはしない。画面と画像の縦横比が違うときは、画像の端（横長の画面では上下）が切れる。平野の朝練見学だけは、横長の画面で下側（グラブと球）を見せる（`object-position: 50% 100%`、上の空を切る）。

本文枠と操作ボタンは画像の上に重ねる。本文枠は一枚絵の表示中も通常と同じ位置・大きさ・下地にする（`docs/ui-frame.md`）。画像ごとに本文枠を変えない。

本文枠に重なる重要部分（試験で記録。本文枠は半透明なので、うっすら透けて見える）：平野の朝練見学のグラブと球（667×375・956×440・1280×720）、大山の白無垢の胸から下。顔・人物の上半身・新聞の一枚絵の重要部分は、どの画面でも本文枠の上にある。

## CG 鑑賞の解放

キットは「本文の並び順で、表示中の行より手前にある一枚絵」をすべて解放する。残す3枚は、すべての経路が必ず通る場面（5-1、章間「新聞と記録」、幕間「行きのバス」）にあり、通らずに並び順で後の場面へ進む経路がないので、キットのままで誤って解放されない。

以前は、5-26 の田原・小宮の分岐の一枚絵が選ばなかった側でも解放されるのを防ぐため、作品側の `game-cg-branches.js` で解放を補っていた。分岐の一枚絵を削除したので、このスクリプトと `index.html` からの読み込み、専用の試験を削除した。
