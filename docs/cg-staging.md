# 一枚絵の配置

`game.js` の `assets.cgs` と `cues`（`cg`）で指定している一枚絵の記録です。現在の一枚絵は9枚で、CG 鑑賞の対象もこの9枚です。

## 方針

- 一枚絵の ID はファイル名（拡張子なし）と同じにし、画像を差し替えても ID とファイル名は変えない。
- 置き場所は `assets/cg/`。1920×1080 の不透明 WebP を、再圧縮・描き足し・左右反転せずに置く。
- CG 鑑賞の題名は場面名にし、「妄想」「イメージ」などの説明は画面に出さない。
- 一枚絵の区間では、通常の立ち絵を重ねない。区間の次の行で、その行の背景と立ち絵に戻す。
- 本文にない出来事や具体的な想像を、一枚絵の側で足さない。本文と接続している場面だけに置く。
- 管理 ID（Magnific ID）は、公開フォルダにも、この記録にも書かない。

## 最初に本文枠を隠して絵を見せる（第5便の試作。`game-reveal.js`）

対象は `c20-004`（涙）・`c29h-012`（影の笑み）・`c35-019`（満面の笑み）の3行だけ。ほかの一枚絵には適用しない。作者がデモプレイで最終判断するための試作採用で、構図の修正より先に、この表示順の演出で試し、必要な絵だけを後で再調整する。

- 通常送り：一枚絵を読み込んでデコードし、画面に出た時点で本文枠（話者名・本文・「タップで進む」）と場面名の札を隠す。次のタップ・送りキー（画面の絵のどこをタップしてもよい）で、同じ行の本文枠を戻して文字の表示を始める。その入力では次の行へ進まない。強制の待ち時間はない。本文枠を隠している間は本文を出さず、既読にもしない。
- AUTO：絵が出てから約1秒後に本文枠を戻し、そのあと既存の文字表示と AUTO の待ち時間。読み込みの時間は1秒に含めない。手で先に戻すと演出のタイマーを取り消す。AUTO を切っても隠れたままにならない（タップで戻せる）。
- 既読SKIP：既読の対象行では一拍を省く。未読で止まったときは通常の送りと同じ。
- 複数行の一枚絵：一拍は最初の行だけ。2行目以降は本文枠を出したまま。
- 保存からの再開・タイトルからの「つづきから」では一拍を省き、本文枠が見える状態で始める（隠している間に保存しても同じ）。永続の状態は追加しない。行の移動・タイトルへの移動・画面の回転でタイマーと隠した状態を残さない。
- 一枚絵の準備前に本文枠だけを先に隠さない（既存の読み込み待ち `game-stage.js` のまま。黒を挟まない）。読み込みに失敗したときは一拍を省いて本文を出す。
- 本文枠は `visibility` で隠すだけなので、位置・大きさ・不透明度・操作ボタンの配置は変わらない（`docs/ui-frame.md`）。

見え方（4つの画面サイズで、本文枠を戻したあとも読み進めて確認）：
- 涙：本文枠を戻したあとも、目と涙の筋が本文枠の上に見え、観客の声（`c20-005a`）まで感情がつながる。
- 影の笑み：つばの影と笑う口元のうち、口元（画像の下から約2割）が本文枠に重なる。本文枠を戻すと、野原の内心（`c29h-013`）を読む間は笑みが半透明の枠越しにしか見えない。最初の一拍では全体が見える。必要なら、口元を上へ寄せる再調整の候補。
- 満面の笑み：PC（1280×720）では口元まで本文枠の上。横向きスマホでは口元が本文枠に重なるが、閉じた笑い目と頬・帽子は見え、「ほらな」から辞任宣言まで笑顔として読める。
- 幕切れ：一拍を足さず、最後の台詞と絵が同時に出る。驚く大山・厳・中田と跳ねる美空は本文枠の上、下の部員は本文枠に重なる。

## 表示サイズと本文枠（`game.css`）

一枚絵は、キットの既定どおりゲームの表示領域全体に敷く（`object-fit: cover`、縦横比は維持）。画像を縮小して本文枠の上に収めたり、画像の下に本文枠用の余白を取ったりはしない。画面と画像の縦横比が違うときは、画像の端（横長の画面では上下）が切れる。平野の朝練見学だけは、横長の画面で下側（グラブと球）を見せる（`object-position: 50% 100%`、上の空を切る）。

本文枠と操作ボタンは画像の上に重ねる。本文枠は一枚絵の表示中も通常と同じ位置・大きさ・下地にする（`docs/ui-frame.md`）。画像ごとに本文枠を変えない。

本文枠に重なる重要部分（試験で記録。本文枠は半透明なので、うっすら透けて見える）：平野の朝練見学のグラブと球（667×375・956×440・1280×720）、大山の白無垢の胸から下。佐々木の花嫁を抱える手袋の両手とドレスの下側（横向きスマホ〜956×440。抱える動作は、2人の顔・首に回した腕・寄りかかる上体で読める）。顔・人物の上半身・新聞の一枚絵の重要部分は、どの画面でも本文枠の上にある。

## CG 鑑賞の解放

キットは「本文の並び順で、表示中の行より手前にある一枚絵」をすべて解放する。4枚とも、すべての経路が必ず通る場面（5-1、5-16、章間「新聞と記録」、幕間「行きのバス」）にあり、通らずに並び順で後の場面へ進む経路がないので、キットのままで誤って解放されない。

以前は、5-26 の田原・小宮の分岐の一枚絵が選ばなかった側でも解放されるのを防ぐため、作品側の `game-cg-branches.js` で解放を補っていた。分岐の一枚絵を削除したので、このスクリプトと `index.html` からの読み込み、専用の試験を削除した。
