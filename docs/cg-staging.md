# 一枚絵の配置（新聞と記録・第2便）

`game.js` の `assets.cgs` と `cues`（`cg`）で指定している一枚絵の記録です。本文・行ID・分岐・保存キー・データ版は変えていません。

## 方針

- 一枚絵の ID はファイル名（拡張子なし）と同じにし、画像を差し替えても ID とファイル名は変えない。
- 置き場所は `assets/cg/`。1920×1080 の不透明 WebP を、再圧縮・描き足し・左右反転せずに置く。
- CG 鑑賞の題名は場面名にし、「妄想」「イメージ」などの説明は画面に出さない。
- 一枚絵の区間では、通常の立ち絵を重ねない。区間の次の行で、その行の背景と立ち絵に戻す。
- 管理 ID（Magnific ID）は、公開フォルダにも、この記録にも書かない。

## 立ち絵と背景

- 5-10 の河本の区間（`c10-015`〜`c10-017`）は、一枚絵の間だけ左右の立ち絵を消し、`c10-018` で一枚絵の前と同じ監督（左、試合用ユニフォーム）と河本（右、私服）に戻す。
- ほかの 5 区間には、もともと立ち絵がない。
- 背景は区間の前後で変えていない。一枚絵は背景の上に重なり、解除すると元の背景が見える。

## 表示サイズと本文枠（`game.css`）

一枚絵7枚は、キットの既定どおりゲームの表示領域全体に敷く（`object-fit: cover`、縦横比は維持）。画像を縮小して本文枠の上に収めたり、画像の下に本文枠用の余白を取ったりはしない。画面と画像の縦横比が違うときは、画像の端（横長の画面では上下）が切れる。平野の朝練見学だけは、横長の画面で下側（グラブと球）を見せる（`object-position: 50% 100%`、上の空を切る）。

本文枠と操作ボタンは画像の上に重ねる。本文枠は一枚絵の表示中も通常と同じ位置・大きさ・下地にする（`docs/ui-frame.md`）。画像ごとに本文枠を変えない。

本文枠に重なる重要部分（試験で記録。本文枠は半透明なので、うっすら透けて見える）：

## 分岐の一枚絵の解放（`game-cg-branches.js`）

キットは「本文の並び順で、表示中の行より手前にある一枚絵」をすべて CG 鑑賞へ解放する。そのままだと、5-26 で小宮の側を選んでも、並び順で手前にある田原の一枚絵が解放され、田原の側を選んでも合流後に小宮の一枚絵が解放される。

固定キットは変えず、作品側の `game-cg-branches.js`（`index.html` でキットの起動直後に読む）で、分岐の中にある 2 枚だけは、その区間を実際に表示したとき（表示中の行が区間の中にあるか、区間の最初の行を既読にしたとき）に限って解放する。ほかの一枚絵の解放はキットのまま。

## 確認方法

- `tests/game/data.js`：一枚絵が 7 枚で ID がファイル名と同じこと、各区間と解除、区間中に立ち絵を重ねないこと、`c10-018` で立ち絵が戻ること、解除後の背景、分岐の一枚絵がその分岐の中だけに出ること、CG 鑑賞の題名に説明語がないこと。
- `tests/game/play.js`：667×375・956×440・1280×720 で、7 枚が縮小・余白なしで表示領域全体を覆うこと、表示開始・維持・解除と通常画面への復帰、区間中の保存・リロード・「つづきから」での同じ画像と配置、本文枠が一枚絵の前・表示中・解除後で同じであること、重要部分が画面内にあること（本文枠に重なるものは記録）、CG 鑑賞への解放、田原と小宮の両分岐で選んだ側の一枚絵だけが解放されることを確かめる。
