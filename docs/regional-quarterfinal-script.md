# 5-14　地方予選

本編初稿。1年目の夏、地方大会準々決勝。北陵戦の8回裏、代打の指名直前まで。

## 本文

準々決勝の朝、日和がベンチに冷えたボトルを並べた。試合が始まるころには、ボトルの下にできた水の輪が、ひとつずつつながっていた。

相手は北陵高校。組み合わせが決まった日に中田先輩が、「毎年、この辺まで来るとあいつらがいる」と言った学校だ。

北陵のエースは、打者が代わっても外寄りに真っすぐを投げた。捕手が構えたミットは、球を受けるまでほとんど動かなかった。遠くから見ていても、ボールが先にミットのある場所を知っているみたいだった。

3回裏。中田先輩がその球を引っ張った。三遊間へ抜けたと思った打球を、深く守っていたショートが横へ出て捕った。一塁への送球を見届けてから、中田先輩は走るのをやめた。

ベンチへ戻ってくるなり、先輩は俺のスコアブックをのぞいた。

中田｜今の、どこにつけた？

俺が外寄りの印を指すと、中田先輩はもう一度ショートのいた辺りを見た。

中田｜あそこまで下がってたか。抜けたと思ったんだけどな。

それからヘルメットを外した。監督のほうを横目で見て、日和から受け取った水をひと口だけ飲んだ。

中田｜……監督、今の打球、見てたか？

日和が答える前に、守備へ出ろと声がかかった。先輩はグラブをつかみ、さっき打球を捕られた場所へ走っていった。

5回には、鳳翔も外寄りの球をライト前に落として1点を返した。塁上の打者がベンチを向いて拳を上げたとき、俺も次の得点を書くつもりでページを開いたままにした。

次の打者が打った球は、またショートの正面に行った。

7回が終わっても、鳳翔の得点欄にはその1点しかなかった。北陵は2点。差は1点なのに、同じ場所に印をつけ続けているうちに、何回も同じ攻撃を見せられている気がしてきた。

8回裏も、打者が2人続けて凡退した。応援席から聞こえていた手拍子がばらつき始めたところで、大山の名前が呼ばれた。

大山は初球の真っすぐを打った。

打球は投手の足元を抜け、二塁ベースのすぐ脇を通った。北陵のセンターが前に出て拾い、大山が一塁を回るより先に、返球が内野へ戻った。

大山はベースへ戻って、ベンチを見た。ヘルメットのつばを指で上げたが、監督は手元の打順表を見ていた。

俺はスコアブックに安打を書いた。8回裏、2アウト、一塁。次の枠が埋まる前に、監督が紙を膝に置いた。

打席へ向かいかけた選手が、その動きに気づいて足を止めた。

監督が立ち上がった。ベンチの奥で、誰かがヘルメットを置き直す音がした。
