# 5-14　地方予選

本編初稿。1年目の夏、地方大会準々決勝。北陵戦の8回裏、代打の指名直前まで。

## 本文

準々決勝の朝、日和がベンチに冷えたボトルを並べた。
試合が始まるころには、
ボトルの下にできた水の輪が、ひとつずつつながっていた。

相手は北陵高校。
組み合わせが決まった日に中田先輩が、
「毎年、この辺まで来るとあいつらがいる」と言った学校だ。

試合前、日和が、新聞から写した北陵の試合結果をベンチの端に広げた。
中田先輩がのぞき込んで、「何点取られてる」と聞いた。

日和｜北陵はここまで3試合で、失点が2。四球は全部で1つだけ。
前の試合の1点も、内野安打から送りバントで進められて、
次の単打で返された点。

中田｜長打では1本も取られてない、ってことだな。

中田先輩が「投げてるの、あいつか」と柵の向こうへ顔を向けた。
応援席に上がる前の三浦が、そこで足を止めて北陵のエースを見ていた。

三浦｜あの人、城南シニアで2つ上だったんです。
あの頃は速かったけど、四球を出し始めると自分から崩れる人で。

三浦｜でも今、捕手のミットがほとんど動いてないですよね。
速さより、外に投げきるほうを取ったんだと思います。

俺はその投手を、今日初めて見る。
地元のやつには、こういう「前から知っている相手」がいるらしかった。

先輩｜去年の秋に当たったときも、外の真っすぐばっかりだった。
分かってたのに、最後はショートの正面に打たされた。

中田｜じゃあ、外は捨てない。待って、引っ張る。
当てにいくから正面に行くんだ。振りきれば三遊間は抜ける。

中田｜最初に抜くのは俺だ。お前らは、それを見てから合わせろ。

そう言うと、中田先輩はバットを2本つかんで、
ベンチ脇の素振りの場所へ歩いていった。

三浦は柵から離れながら、中田先輩の背中を見ていた。
自分の話のどこが使われたのか、確かめるみたいだった。

北陵のエースは、打者が代わっても外寄りに真っすぐを投げた。
捕手が構えたミットは、球を受けるまでほとんど動かなかった。
遠くから見ていても、
ボールが先にミットのある場所を知っているみたいだった。

3回裏。中田先輩がその球を引っ張った。
三遊間へ抜けたと思った打球を、深く守っていたショートが横へ出て捕った。
1塁への送球を見届けてから、中田先輩は走るのをやめた。

ベンチへ戻ってくるなり、先輩は俺のスコアブックをのぞいた。

中田｜今の、どこにつけた？

俺がスコアブックを見て外寄りだったと答えると、
中田先輩はもう一度ショートのいた辺りを見た。

中田｜あそこまで下がってたか。抜けたと思ったんだけどな。

それからヘルメットを外した。
監督のほうを横目で見て、日和から受け取った水をひと口だけ飲んだ。

中田｜……監督、今の打球、見てたか？

日和が答える前に、守備へ出ろと声がかかった。
先輩はグラブをつかみ、さっき打球を捕られた場所へ走っていった。

守備位置に着くと、中田先輩はグラブでマウンドの先輩を指した。

中田｜打たせていいぞ！　こっちに来たら俺が取る！

5回裏、2アウト2塁。
打順は、去年の秋に北陵のエースと当たった先輩に回ってきた。

次の打者が待つ場所へ向かう前に、先輩はバットを握り直した。
一度ほどいた指を、また同じ順に巻きつけている。
肩が、守備から戻ってきたときより上がっていた。

監督が打順表を持ったまま、俺のほうへ体を寄せてきた。

美空｜平野くん。今、打順どこ？

平野｜先輩です。
去年の秋、あの投手に外の真っすぐで打ち取られてから、少し――

美空｜まあ、大丈夫でしょ。

監督はそれだけ言うと、打順表に目を戻した。
指は、大山の名前のところで止まっていた。

ベンチの段の上で、先輩の足が止まっていた。
俺たちのすぐ後ろだった。

先輩｜……大丈夫だってよ。監督が。

先輩はもう一度だけバットを握り直して、段を降りた。
肩はまだ、少し上がっていた。

初球の外の真っすぐを、先輩は見送った。
2球目も同じ高さに来た。今度はバットが出た。
引っ張りにいかず、踏み込んで、外の球をそのまま右へ押し返した。

打球はライト前に落ちた。2塁の走者が帰って、鳳翔は1点を返した。
1塁に着いた先輩がベンチを向いて拳を上げたとき、
俺も次の得点を書くつもりでページを開いたままにした。

拳を下ろした先輩は、自分の手のひらを一度見た。
それから、1塁コーチに何か言われて、リードを取り直した。

次の打者が打った球は、またショートの正面に行った。

7回が終わっても、鳳翔の得点欄にはその1点しかなかった。北陵は2点。
差は1点なのに、外寄りの速球で打ち取られるのを見続けているうちに、
何回も同じ攻撃を見せられている気がしてきた。

8回裏も、打者が2人続けて凡退した。
応援席から聞こえていた手拍子がばらつき始めたところで、
大山の名前が呼ばれた。

大山は初球の真っすぐを打った。

打球は投手の足元を抜け、2塁ベースのすぐ脇を通った。
北陵のセンターが前に出て拾い、
大山が1塁を回るより先に、返球が内野へ戻った。

大山はベースへ戻って、ベンチを見た。
ヘルメットのつばを指で上げたが、監督は手元の打順表を見ていた。

俺はスコアブックに安打を書いた。8回裏、2アウト、1塁。
次の枠が埋まる前に、監督が紙を膝に置いた。

打席へ向かいかけた選手が、その動きに気づいて足を止めた。

監督が立ち上がった。ベンチの奥で、誰かがヘルメットを置き直す音がした。
