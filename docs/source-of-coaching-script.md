# 幕間「あと十本」／5-6「指導の出所」

本編初稿。幕間は第一章の翌日。5-6では、平野が美空の指示の出どころを疑うところまで描く。

## 幕間：あと十本

翌日の練習が終わった。先輩たちに何球も投げたはずの大山が、まだバットを片づけていなかった。

ネットの前の台に球を載せて、一度振る。跳ね返った球が足元まで戻ってくるあいだに、次の球を台に載せた。

平野｜監督なら、もう帰ったぞ。

大山｜知ってる。あと十本。

俺は帰りかけていた足を止めた。ネットの下を転がってきた球を拾い、ボールかごを足元に引き寄せた。

## 共通：バント守備

何日かして、一塁に走者を置いてバントの守備を練習した。

俺はベンチから、打球を拾った選手と送球先を書いていた。見慣れない練習は、部室の古い資料を見ておくと、誰がどこへ動くのか追いやすい。

投手の前にバントが転がった。投手は拾って二塁へ投げたが、一塁から走った選手の足が先にベースへ着いた。

二塁で球を受けた先輩が一塁を見た。打った選手も、もう一塁を駆け抜けていた。

二人とも残った。俺が記録に鉛筆を置くと、走者は練習のために一塁へ戻った。

投手は返ってきた球を打つ先輩に渡し、また構えた。監督は何も言わなかった。

次の打球も、投手の前だった。さっきより足元に近い。投手は拾うなり一塁へ投げ、今度は走者の足より先にミットが鳴った。

次の欄に「一塁」と書き、その横に丸をつけた。投手が球を返し、次の組と入れ替わり始めたところで、監督の声がした。

美空｜まず一つ。二つ欲しがって、ゼロにするな。

グラウンドから揃って「はい」と返った。俺は、つけたばかりの丸を見直した。

二塁で間に合わなかった直後なら分かる。でも今の投手は、もう一つ取って、列の後ろへ戻るところだった。

一つずつ取れ、なら中学のときにもよく聞いた。でも、監督がそのあとに続けた言葉まで、どこかで聞いた気がした。

**選択肢：指示の意味を聞く／去年の資料を見返す**

## A：指示の意味を聞く

次の組が守備に就くまで、監督はベンチの端にいた。俺はスコアブックを開いたまま、横から声をかけた。

平野｜監督。二塁で間に合いそうな球でも、一塁ですか？

監督は一度、俺のほうを向いた。返事が来るかと思って待ったが、目はすぐグラウンドに戻った。

次の打者はまだ落としたバットを拾っているところだった。誰かのプレーを見ていて答えられない、というわけでもなさそうだった。

美空｜まず一つ。そう言ったでしょ。

怒られたのかと思って、いったん座り直した。

「まず一つ」。二度目も、句切るところが同じだった。紙に太い字で書かれていたその一行を思い出した。去年の練習資料を見返していたとき、前の監督の名前が入った古い紙が混じっていた。

俺が知りたいのはどっちの塁に投げるかだった。返ってきたのは、紙に書かれていたところまでだった。

## B：去年の資料を見返す

ベンチの脇の棚から、去年の練習資料を抜いた。守備のページは何枚かまとまっていて、バントだけでも走者の位置ごとに分かれていた。

その間に、色の違う紙が一枚混じっていた。前の監督の名前が入っている。去年の人が、古い資料からこのページだけ一緒に綴じたらしい。

一塁と二塁を結んだ図の下に、太い字で書き込みがあった。

『まず一つ。二つ欲しがって、ゼロにするな』

さっきの声のまま読めた。俺は、そんな言い方だったなと思ってから、逆だったと気づいた。紙を見た覚えがあるから、さっきの言葉が引っかかったのだ。

資料を閉じかけて、指を挟んでおいた。今の監督なら、この図を見ずにどこまで説明するだろう。

## 合流：ベンチの端

給水に入ると、さっきまでベンチの前にいた選手たちが、ボトルの置いてあるほうへ行った。監督だけが、同じところに立っていた。

平野｜あの、監督。さっきのバント守備ですけど。

美空｜うん。

平野｜あの言い方、誰かに教わったんですか？

返事を待つあいだ、俺は監督の顔を見ていた。口が少し開いて、頬からすっと色が引いた。

給水台のほうでは、さっきと同じように先輩たちの笑い声がしていた。

監督の目が、俺の顔からスコアブックへ落ちた。鉛筆を挟んだままだったので、開いて見せようとした。

美空｜……馬鹿野郎。余計なことを考えるな。

声だけ聞けば、グラウンドの誰かが叱られたみたいだった。辺りを見ても、監督の前に立っているのは俺だけだった。

平野｜でも、前の監督の資料にも同じことが――

監督が一歩詰めた。

「書いてあります」と続ける前に、口を塞がれた。
