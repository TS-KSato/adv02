# 5-4　美空の登場

本編初稿。「記録する1年生」に続く。平野は美空を間近で見て、監督と普通に話しただけなのに部員たちがそれを気にすることに気づく。

## 本文

試合形式の練習は3回で切り上げた。残りの時間で内野の守備をもう一度やることになり、俺はベンチに残って3回の記録を埋めていた。

3回の最後の欄を埋めたとき、グラウンドの声がふっと途切れた。

平野｜ん？　なんだ？

顔を上げると、さっきまで散らばっていた先輩たちが、ベンチの前に一列に並んでいた。靴の先まで揃っている。軍隊みたいだった。

列の端で「監督」と声がして、先輩たちが一斉に帽子を取った。

俺も鉛筆を置いて立った。

神条監督は、入口で立ち止まらずに、こっちへ歩いてきた。思っていたより背が高い。帽子の下から出た黒髪が、歩くたびに肩の後ろで揺れた。

近くまで来て、監督が一度、俺のほうを見た。

きれいな人だった。俺が挨拶をしそびれたことに気づいたのは、その人が通り過ぎてからだった。

平野｜お、お疲れさまです。

俺が頭を下げたときには、もう隣の先輩が帽子をかぶり直していた。

監督はベンチの端に立ち、内野を見た。ノックを打つ先輩が球を持ち直すと、内野が4人とも腰を落とした。

まだ球が飛んでもいないのに、誰かが「1つ」と声を出した。反対側から「はい」と返った。さっきまでばらばらだった声で、今は球を渡す先が分かった。

三遊間に打球が飛んだ。追いついた選手が捕ったところで一度止まったので、1塁への送球が遅れた。

美空｜田中。捕って終わりじゃない。送球まで。

中田｜はい！

返事をした選手が、さっきと同じ位置へ戻った。もう1本、と手を上げる。先輩がまた同じあたりへ打った。

今度は捕ったあとに足が止まらなかった。1塁の先輩は胸の前で送球を受け、すぐ球を返した。

あれなら走者がいても間に合いそうだった。そう思って見ていると、その選手が交代でベンチに戻ってきた。

1年生｜え？　先輩って中田じゃ……

中田｜わかってるよ。

中田先輩はグラブを膝の上で裏返した。返事をしたときは真顔だったのに、口元が緩んでいた。

俺はスコアブックに目を戻した。3回の最後に残った消しゴムのかすを払った。

次の練習の記録は、どこから書こう。さっきの2本は結果だけならどちらも捕って投げただけだ。1本目と2本目の違いは、余白にでも書かないと残らない。

美空｜記録、見せて。

すぐ近くで声がした。顔を上げると、監督が俺の膝の上を見ていた。

平野｜はい。3回ですか？

美空｜うん。

開いたまま持っていった。風でページの端が浮いたので、監督が読んでいるところにかからないよう、指で押さえた。

監督は俺の手元を見たまま、しばらく何も言わなかった。

外野側から、打ち返した球がネットに当たる音がした。それきり、次の打球の音がしなかった。

美空｜そこ、開いておいて。

平野｜はい。

それだけだった。俺は元の場所へ戻り、開いたページの端に鉛筆を置いた。

中田先輩が、グラブを膝に乗せたまま俺を見ていた。その向こうで、別の先輩が、一度目をそらしてからもう一度こっちを見た。

練習のほうを見ると、大山がバットを肩に乗せて立っていた。次の打者を呼ぶ声がした。

大山も、こっちを見ていた。
