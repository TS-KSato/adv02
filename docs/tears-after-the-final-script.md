# 5-20　一人の涙、別々の意味

本編初稿。龍成戦の試合終了直後。スタンドから見下ろした鳳翔の一枚絵を想定し、ベンチ側で聞こえる言葉を重ねる。

## 本文

整列の声で、ようやく鉛筆を置いた。白線に並んだ鳳翔の選手は、帽子を取って頭を下げた。中田先輩だけが少し遅れて頭を上げた。帽子をかぶり直そうとして、結局、手に持ったまま列を離れた。

ベンチに戻ってきた先輩たちは、誰も荷物に手をつけなかった。中田先輩は腰掛けの前で膝に手を置いた。隣には、試合中ずっとヘルメットを用意していた控えの先輩が立っていた。

その2人の間から、監督の横顔が見えた。

監督は掲示板を見ていた。頬を伝った涙が、あごの先から落ちた。拭おうともしなかったので、次の涙も同じところを通った。

ネットの向こうで、誰かが「あの監督さんも泣いてる」と言った。

鳳翔側のスタンドから、拍手がひとつ起きた。少しずつ数が増えた。夕日がベンチの奥まで差し込んで、監督の頬と、先輩たちが膝につけてきた土を照らしていた。

スタンドから降りてきた大山が、ベンチ脇の柵まで松葉杖で来た。柵をつかんだまま、美空から目を離さなかった。

大山｜美空……俺と行きたかったんだよな。俺が出てりゃ、あんな顔させずに済んだのに。

声のした方を向きかけて、中田先輩の肩が揺れているのに気づいた。

中田｜美空監督は……今年こそ、俺と結婚したかったはずなのに……。

控えの先輩が腰掛けの端に座り、ヘルメットを膝に置いた。つばをぬぐっているうちに、そこへ涙が落ちた。

先輩｜俺、一度でいいから呼ばれたかったな。監督に、打ったとこ見せたかった。

監督が鞄の口を開けた。出してきたタオルに、何度も折り直した紙が引っかかっていた。俺のいるところから「レジ・品出し」の文字が見えた。

美空｜……レジ、やらなきゃ……。

俺は口を開きかけた。目の前では中田先輩が、まだ監督のほうを向いたまま泣いていた。柵の向こうでは、大山が口を真一文字に結んでいた。

拍手は、まだ続いていた。

誰かが、「来年こそ」と言った。中田先輩はうつむいたまま、手に持っていた帽子のつばを直した。

俺はベンチに置いたスコアブックを閉じた。最後の打者の欄だけ、まだ白かった。
