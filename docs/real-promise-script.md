# 5-36　本当の約束

本編初稿。優勝ルートE5の幕切れ。美空がマイクを受け取った直後から。

## 本文

監督はマイクを口元まで持ち上げた。大山は、もう一歩そっちへ出た。

美空｜やったー！　私、今日で監督辞めまーす！　引き籠れるー！

拍手が止まった。外野席のほうで、少し遅れて笛がひとつ鳴った。

先輩｜え？

鳳翔の応援席で、母親のひとりが、隣の人の腕に触れた。膝の上にはまだ、広げたままの応援タオルがあった。

鳳翔の母親｜今、なんて？

大山｜……ん？

監督はもう大山を見ていなかった。マイクを持ったまま、鳳翔の応援席を見上げた。

美空｜お父さん！　約束どおりでいいよね？

厳は応援席のいちばん前まで下りてきていた。手すりにかけた手の下で、握ったままの帽子がつぶれた。

美空｜甲子園で優勝したら監督辞めて、ずっと家にいていいって言ったよね。これでもう、働きに出なくていいんだよね？

大山の口が開いた。何か言いかけて、監督の顔を見直した。

応援席で、厳は掲示板を見た。4対3。最後のアウトが決まった瞬間、席を立って隣の客と手を叩き合わせた。その手で、今は帽子を握りつぶしていた。

厳には、県大会でさえ勝ち切れない年が続いた記憶があった。あの条件なら、監督を続けるうちに外で人と関わることにも慣れるだろうと思った。掲示板の数字は、何度見ても変わらなかった。

厳｜……い、いや、その、あれは……言葉の綾というか……。

美空｜でも言ったよね！

厳の視線が掲示板から娘に戻った。手すりの下で、美空はさっきと同じ顔で笑っていた。

厳｜う……うん……。

ベンチの出口で、日和が俺のほうを向いた。俺も日和を見た。インタビュアーが美空のマイクに手を伸ばし、途中で止めた。

監督はマイクを持ったまま、うれしそうに両腕を上げた。

ええええええーっ！？
