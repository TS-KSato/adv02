# 5-3　記録する1年生

本編初稿。「練習へ交ざる」のどちらの選択肢からも同じ場面へ進む。

## 本文

翌日もグラブを持っていった。

練習が始まる前に、昨日の1年が俺を見つけた。お互い名前も聞いていないのに、向こうはちゃんと覚えていた。

1年生｜なあ、そこにいて。投げるから。

そいつはノックを1本受けると、1塁へ投げた。球はほとんど真っすぐ来て、最後に少しだけ先輩の右へ流れた。

1年生｜どうだった？

平野｜最後だけ。捕る人が動くほどじゃなかったけど。

そいつは1塁の先輩を見た。先輩はもう、流れたほうへ片足をずらして立っていた。

1年生｜あの人、俺が投げる前にもう動いてるんだよな。もう1回、見ててくれ。

2球目は真ん中に入った。そう言うと、そいつは喜ぶより先に自分の足元を見た。さっきと何が違ったのか、思い出そうとしているらしかった。

俺もグラブをはめ、列の後ろへ回った。昨日より前のほうに並べた。

それから何日かして、部員を二組に分けて試合形式の練習をした。

出番を待っていると、先輩がベンチの隅からスコアブックを引き寄せた。角がめくれて、表紙はきちんと閉まらなくなっていた。

先輩｜平野、次の組だろ。呼ばれるまで、これ頼む。

平野｜どこからですか？

先輩｜2回裏から。打順表は表紙の裏な。

グラブを膝に置いて鉛筆を持った。守備が始まると、つい白球のほうを見てしまって、走者がどこで止まったかを見落としかけた。

次は、打った音がしたところで先に走者を見た。走者が2塁を回りかけて、急に足をそろえた。打者が1塁に着いたのは、そのあとだった。

自分が守っているときは、自分に球が来るかどうかばかり考える。ここから見ていると、球の来なかったところで先に動いたやつがいる。

そういうことは、結果の横の空いたところに、読める程度の字で書いておいた。

交代で守備に入った回、俺は正面のゴロを一度こぼした。拾い直したときには、走者はもう1塁に着いていた。

後ろから「次、1つ！」と声がした。次の打球は俺のところには来なかった。

ベンチに戻ってから、俺がこぼした打球をエラーと記録した。その次の安打で、1塁走者が3塁まで行ったことも書き足した。

練習のあと、先輩がスコアブックをのぞいた。

先輩｜3回、ヒット2本で1点か？

平野｜1本です。先頭は四球で、その次は俺がこぼしました。

先輩｜ああ、あれお前か。

そこまで思い出さなくていい。

先輩の指が、その次の打席で止まった。1塁の走者がいつ3塁まで行ったか聞かれ、俺が書き足した余白を見せた。

先輩は一度グラウンドを見た。それから、ページの端を折らずに、間に打順表を挟んだ。

先輩｜ここ、明日もう1回見たい。閉じといていいぞ。

次の日も、最初はグラブを持って列に並んだ。記録を頼まれたのは、出番のないあいだだけだった。

その次は、守備から戻ると、俺が座っていたところにスコアブックが置いてあった。開くと、先輩が記録を終えた行の下に短い線が引いてあった。俺はその次の行から書いた。

向こうでは、1年が2人、空いた守備位置に同時に入ろうとしていた。1人が譲ったかと思うと、次の交代で、どちらが先に行くかでもう揉めている。

入学した日なら、俺もあの辺で次の番を待っていたと思う。実際、最初の何日かはそうしていた。

その日は、2人が入れ替わるのを見て、さっきの送球はどっちだったか聞きに行った。見分けられないまま書くと、あとで聞かれたとき困る。

それから何日かして。ベンチに座り、先輩が置いていった打順表を写していた。

先輩｜平野、今日の記録――

顔を上げると、先輩は俺の膝を見た。スコアブックはもう開いていた。

先輩｜……早いな。

平野｜まだ名前しか書いてませんよ。

グラウンドで最初の打者がバットを構えた。投手が1塁側を一度見てから、足を上げた。

俺は打者の名前の横に、鉛筆の先を置いた。

グラブは今日も持ってきていた。鞄の中で、朝入れたときのままになっていた。
