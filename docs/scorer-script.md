# 5-3　記録する1年生

本編初稿。「練習へ交ざる」のどちらの選択肢からも同じ場面へ進む。

## 本文

翌日もグラブを持っていった。

練習が始まる前に、三浦が俺を見つけた。
昨日、給水台で言ったことを、向こうはちゃんと覚えていた。

三浦｜なあ、そこにいて。投げるから。

三浦はノックを1本受けると、1塁へ投げた。
球はほとんど真っすぐ来て、最後に少しだけ先輩の右へ流れた。

三浦｜どうだった？

平野｜最後だけ。捕る人が動くほどじゃなかったけど。

三浦は1塁の先輩を見た。
先輩はもう、流れたほうへ片足をずらして立っていた。

その先輩が、グラブから球を出しながら三浦に言った。

先輩｜今の、右に逃げてる。次は胸な。

三浦｜はい！

三浦｜あの人、俺が投げる前にもう動いてるんだよな。もう1回、見ててくれ。

2球目は先輩の胸に入った。
1塁の先輩が「ナイスボール」と短く言って、球を返した。
三浦は喜ぶより先に自分の足元を見た。
さっきと何が違ったのか、思い出そうとしているらしかった。

俺もグラブをはめ、列の後ろへ回った。昨日より前のほうに並べた。

それから何日かして、部員を2組に分けて試合形式の練習をした。

出番を待っていると、先輩がベンチの隅からスコアブックを引き寄せた。
角がめくれて、表紙はきちんと閉まらなくなっていた。

先輩｜平野、次の組だろ。呼ばれるまで、これ頼む。

平野｜どこからですか？

先輩｜2回裏から。打順表は表紙の裏な。

グラブを膝に置いて鉛筆を持った。
守備が始まると、つい白球のほうを見てしまって、
走者がどこで止まったかを見落としかけた。

次は、打った音がしたところで先に走者を見た。
走者が2塁を回りかけて、急に足をそろえた。
打者が1塁に着いたのは、そのあとだった。

守備についていると、どうしても自分の守備範囲に目が行く。
ベンチからだと、打球に触らなかった選手の動きまで見えた。

そういうことは、結果の横の空いたところに、
読める程度の字で書いておいた。

交代で守備に入った回、俺は正面のゴロを一度こぼした。
拾い直したときには、走者はもう1塁に着いていた。

拾った球を投手へ返すと、三浦がこっちへ顔を向けていた。

三浦｜平野！　切り替え！　次1つ！

平野｜おう！　次1つ！

グラブを一度叩いて、腰を落とし直した。
次の打球は俺のところには来なかった。

ベンチに戻ってから、俺がこぼした打球をエラーと記録した。
その次の安打で、1塁走者が3塁まで行ったことも書き足した。

練習のあと、先輩がスコアブックをのぞいた。

先輩｜3回、ヒット2本で1点か？

平野｜1本です。先頭は四球で、その次は俺がこぼしました。

先輩｜ああ、あれお前か。

そこまで思い出さなくていい。

先輩の指が、その次の打席で止まった。
1塁の走者がいつ3塁まで行ったか聞かれ、俺が書き足した余白を見せた。

先輩は一度グラウンドを見た。
それから、ページの端を折らずに、間に打順表を挟んだ。

先輩｜ここ、明日もう1回見たい。閉じといていいぞ。

次の日も、最初はグラブを持って列に並んだ。
記録を頼まれたのは、出番のないあいだだけだった。

その次は、守備から戻ると、
俺が座っていたところにスコアブックが置いてあった。
開くと、先輩が記録を終えた行の下に短い線が引いてあった。
俺はその次の行から書いた。

向こうでは、1年が2人、空いた守備位置に同時に入ろうとしていた。
1人が譲ったかと思うと、
次の交代で、どちらが先に行くかでもう揉めている。

入学した日なら、俺もあの辺で次の番を待っていたと思う。
実際、最初の何日かはそうしていた。

その日は、2人が入れ替わるのを見て、
さっきの送球はどっちだったか聞きに行った。
見分けられないまま書くと、あとで聞かれたとき困る。

それから何日かして。
ベンチに座り、先輩が置いていった打順表を写していた。

先輩｜平野、今日の記録――

顔を上げると、先輩は俺の膝を見た。
スコアブックはもう開いていた。

先輩｜……早いな。

平野｜まだ名前しか書いてませんよ。

大山がマウンドに上がった。
足元の土を2度ならして、捕手のほうを向いただけだった。
それなのに、ベンチから見るグラウンドが、
ひと回り狭くなった気がした。

最初の打者がバットを構えた。
大山は1塁側を一度見てから、足を上げた。

俺は打者の名前の横に、鉛筆の先を置いた。

ミットが鳴った。
打者は見送った。見送ったというより、
バットを出すところまで行かなかったように見えた。

捕手の先輩は、捕ったまますぐには返さなかった。
ミットを外しかけて、左手を一度開き、また握った。

別の先輩｜いってえ……

大山｜芯で捕れ。

別の先輩｜捕ったわ。……何だよ、今の球。

ショートから「ナイスピッチ」と声が飛んだ。
捕手の先輩は首を一度振ってから、やっと球を返した。
大山はそれを受けると、もう次の打者を見ていた。

俺は1球目の欄に、見逃しのストライクを書いた。

グラブは今日も持ってきていた。
鞄の中で、朝入れたときのままになっていた。
