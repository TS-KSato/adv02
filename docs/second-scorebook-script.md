# 章間　二冊目

本編初稿。新年度の朝、部室からグラウンドへ。

## 本文

4月。2年になって最初の朝練の日、着替えに部室へ入ると、棚の下の段が空いていた。去年まで3年の先輩たちがスパイクを置いていたところだ。

俺が鞄から去年のスコアブックを出すと、向かいで練習用のボールを数えていた日和が顔を上げた。

日和｜あ、ちょうどよかった。机の上の、平野くんの分。

机には同じ色のスコアブックが2冊あった。手前の1冊を取ると、表紙の隅に俺の名前が書いてあった。去年のは背が割れて、手を離すといつも同じところで開いた。新しいほうは、開いてもすぐ閉じた。

平野｜去年の、まだページ残ってるけど。

日和｜龍成の記録、去年のも何度も見返すでしょ。今年の試合が混ざると探しにくいから。

日和はもう1冊を手に取った。そっちの表紙には日和の名前があった。

グラウンドからバットの音がして、日和はボールのカゴを持って出ていった。俺は古いスコアブックを鞄の奥にしまい、新しいほうを持って後を追った。

グラウンドの入口に、見覚えのない背中が2つあった。大柄なほうが柵の前で足を止めて、内野へ飛んだ打球を追っていた。もう1人は、練習の邪魔にならないようか、通りかかる先輩がいるたびに入口の端へ寄った。

去年の今ごろは、俺もあそこで練習を見ていた。中へ入っていいのかも分からず、しばらく立っていた。

背後からスパイクの音がして、大山が俺の隣に並んだ。大柄なほうの足元に、使い込んだキャッチャーミットが置いてあった。

大山｜あのデブ、使えそうだな。

そう言いながら、大山は二人のほうへ歩き出した。
