# 5-23　厳が語る娘の決意

本編初稿。秋の放課後。先輩たちが残した資料が厳の手に渡る。

## 本文

秋になって、部室の窓を開けていると、練習が終わるころには寒くなった。俺が窓を閉めて振り返ると、机の端に重ねてあったファイルを、監督が上から1冊ずつ持ち上げていた。

平野｜引退した先輩たちからです。監督に読んでほしいって。

監督は「中田」と大きく書かれた表紙を開いた。投球コースの図と細かい字で埋まったページを、2枚ほどめくった。

廊下から足音がして、厳さんが戸口に立った。

厳｜美空。明日から守備はこのメニューでやってみろ。場所は下に書いてある。

監督は差し出された紙を受け取ると、ほとんど入れ替わりに、中田先輩のファイルを父親に渡した。

美空｜あ、これ。なんかお父さんに読んでほしいって。

厳｜俺に？

厳さんはファイルを机に置いて開いた。さっき監督が通り過ぎた図のところで手が止まった。

厳｜……こいつ、去年の龍成戦まで見返したのか。

俺が棚から去年の記録を出すと、厳さんは日付を確かめて、2冊を横に並べた。武藤が見送った球を古い方で確かめると、新しい方の同じ打者の欄を見た。それから立ったまま読むのをやめ、椅子を引いた。

厳｜よく見てるな。……俺がいなくなってからも、こんなに残してたのか。

少し間を置いてから、厳さんはファイルの表紙に目をやった。

厳｜中田か。俺に見せるつもりで、ここまでやったのか。

俺が口を開きかけたところで、監督が残りのファイルを持ってきた。厳さんは机の上を空けて、全部受け取った。

厳｜美空、よく持ってきてくれたな。

美空｜ん？　うん。

監督は椅子の背に掛けていた鞄を取った。明日からの練習メニューを半分に折ってしまうと、俺に「じゃあ、また明日」と言って出ていった。

厳さんはもう別のファイルを開いていた。

厳｜就任した日の晩にな、あいつが甲子園で一番になるって言ったんだ。こっちは十何年かけても届くかどうかだと思ってた。……そこまでやる気なら、俺も出せるものは出すと言ったよ。

平野｜それで、明日の練習も。

厳｜ああ。前のやり方で通ると思ってたが、こいつらの記録も見て考え直さないとな。

厳さんは鞄からノートを出して、武藤の名前と試合の日付を書き写した。中田先輩のファイルは、机のいちばん手前に開いたままだった。

（先輩。名前は、ちゃんと覚えてもらえました。）
