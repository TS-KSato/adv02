# 5-23　厳が語る娘の決意

本編初稿。秋の放課後、鳳翔の部室で資料を渡す平野から、その晩の神条家へ移る。厳が資料をどう受け取ったかは、平野には分からない。

## 本文

秋になって、部室の窓を開けていると、練習が終わるころには寒くなった。俺が窓を閉めて振り返ると、机の端に重ねてあったファイルを、監督が上から1冊ずつ持ち上げていた。

平野｜引退した先輩たちからです。監督に読んでほしいって。

監督は「中田」と大きく書かれた表紙を開いた。投球コースの図と細かい字で埋まったページを、2枚ほどめくった。

監督はしばらく図を眺めたあと、ファイルを閉じ、机の端の分もまとめて抱えた。俺は棚に残っていた記録の整理を続けた。

その晩、神条家。美空が居間のテーブルにファイルを置くと、厳は書きかけの練習メニューから顔を上げた。

厳｜美空。明日から守備はこのメニューでやってみろ。場所は下に書いてある。

美空｜あ、これ。なんかお父さんに読んでほしいって。

厳｜俺に？

厳はファイルを机に置いて開いた。美空が学校で読み飛ばした図のところで手が止まった。

厳｜……こいつ、去年の龍成戦まで見返したのか。

中田の記録には、今年打たれた球の下に、同じコースで打ち取った去年の試合の日付が書いてあった。厳は立ったままその日付を読み返し、それから椅子を引いた。

厳｜よく見てるな。……俺がいなくなってからも、こんなに残してたのか。

厳はファイルの表紙を見直した。題名より大きな字で「中田」と書いてある。

厳｜中田か。俺に見せるつもりで、ここまでやったのか。

美空が残りのファイルも押しやると、厳は練習メニューを美空に渡し、空いたところに全部並べた。

厳｜美空、よく持ってきてくれたな。

美空｜ん？　うん。

美空は練習メニューを受け取ると、畳んで鞄に入れ、自分の部屋へ戻った。

厳は次のファイルを手に取った。表紙をめくったところに「監督へ」と書いてあった。

就任した日の晩、美空は家で、みんなの前で甲子園で一番になると言ったことを話した。厳は十何年かけても届くかどうかと思ったが、そこまでやる気ならと、出せるものは出すと言った。

あの晩と違って、今日は選手たちの手で書かれた記録が目の前にあった。

厳｜……明日の守備、さっきの紙だけじゃ足りんな。

厳はノートを開き、武藤の名前と試合の日付を書き写した。

中田のファイルは、机のいちばん手前に開いたままだった。
