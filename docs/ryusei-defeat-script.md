# 5-19　龍成との決戦、敗退

本編初稿。1年目の地方大会決勝。大山を欠いた鳳翔が龍成と甲子園出場を争う。

## 本文

決勝の朝。日和が貼った打順表に、大山の名前はなかった。ライトの欄には昨日、代わりに入った先輩の名前があった。

試合前のノックで、その先輩は右中間の打球に回り込んだ。大山なら捕っていた高さだ。先輩は無理に手を出さず、跳ねた球を拾って、振り返りざまに中継へ返した。走者がいたら、少なくとも余計な塁は与えない返球だった。

監督がそのライトを見て、俺に聞いた。

美空｜昨日、途中から出た子？

平野｜はい。大山の代わりです。

美空｜そう。

監督は打順表の守備位置を確かめると、紙を日和に返した。大山が出る日の確認と、かかった時間は変わらなかった。

そのすぐあと、ベンチの奥から声がした。

先輩｜大山がいないんだ。今日の決勝点、俺が取る。

中田｜お前はまず塁に出ろ。俺が返してやる。

先輩｜俺が返す側ですよ。

どっちも監督のほうを見ていた。打順表では、2人の名前は縦に並んでいた。

向かいの龍成ベンチで、野原監督は鳳翔の打順表と、準決勝までの記録を見比べていた。

野原｜大山は出ない。先発は昨日と同じだ。追い込まれると低い球を振らされる。打てる高さなら、カウントが浅くてもいけ。

顔を上げると、鳳翔の選手がベンチの前へ出てきた。声は準決勝のときより大きかった。美空はその後ろで、いつも通りの顔をしていた。

野原｜（あれだけの選手が抜けて、声が落ちるどころか大きくなるのか。……何か切り札でもあるのか。）

試合が始まると、龍成は早いカウントから振ってきた。鳳翔も四球を選び、進塁打で走者を進めた。2点目が入ったときは、ホームを踏んだ先輩と走者を返した先輩が、同じタイミングで美空のほうを向いた。

7回表、2対2。龍成は先頭が出塁し、そのまま1塁に走者を置いて、打順が4番に回った。

場内アナウンス｜4番、ファースト、武藤大吾。

名前を呼ばれて立った選手の背中は、大きかった。打席に入ると、投手をじっと見た。1塁走者のほうは、一度も見なかった。

初球、内寄りの速球。捕手が構えたところに来た。

武藤は腕をたたんで振り抜いた。白球は左翼線の内側を高く飛んで、そのままスタンドに入った。

1塁走者がホームを踏んだ。武藤はそのあとをゆっくり回り、ベンチへ帰るまで何度も左翼席を見た。俺は、龍成の得点欄に続けて2点を書いた。

監督は電光掲示板を見上げた。龍成の数字が「4」に変わると、眉間にしわが寄った。

中田｜監督、まだ諦めてねえぞ。声出せ！

グラウンドから返事が重なった。俺は、昨日の求人の紙を見たときの監督の顔を思い出した。

9回裏。鳳翔は安打と四球で、走者を2人出した。2アウト、1・2塁。ベンチでは、誰も腰掛けに座っていなかった。

打球がライトへ上がった瞬間、2人の走者は走り出した。2塁走者が3塁を回る。その先には、右手を大きく回しているコーチがいた。

龍成のライトは、打球の下からほとんど動かなかった。

グラブが閉じた。

龍成のライトが、捕った球を握ったままマウンドへ駆けた。内野からもベンチからも選手が駆け寄り、マウンドの土がユニフォームの輪に隠れた。

歓声が大きくなった。掲示板には、鳳翔の「2」と龍成の「4」が、さっきと同じ明るさで光っていた。

俺はまだ鉛筆を握っていた。鳳翔のベンチからは、誰も次の打者の名前を呼ばなかった。
