# 12月の記録（章間）

12月の練習後と、その翌日の投内連係。5-25「父親たちと取材」と 5-26 の前の「二冊目」のあいだに置く短い場面です。部室（`cwinter-001`〜`cwinter-020`、`hosho-clubroom`）から、翌日のグラウンド（`cwinter-021`〜`cwinter-034`、`hosho-field-afternoon`）へ移ります。立ち絵は出しません。

## 本文

12月。全体練習が終わるころには、部室の窓が白く曇っていた。
机では日和が、明日の組分けの紙を広げていた。

俺は今日のノックの記録を清書しながら、紙の空いた枠を見た。
誰がどこに入るかは、もう聞かなくても半分は分かった。

日和｜明日のノック、内野は2組。平野くんは2組目のセカンドね。

平野｜岡田は？

日和｜サード。三浦くんは外野。先輩に、返球を見てほしいって言われたって。

日和が紙の端を押さえたまま、鉛筆の尻で棚を指した。
言われる前に、俺は2段目からセロハンテープを取って渡した。

戸が開いて、冷えた空気と一緒に大山が入ってきた。
挨拶もせずに棚の前へ行き、対戦校のファイルを1冊抜いた。
龍成の分だった。

大山はそのまま、ファイルを脇に挟んで戸口へ戻りかけた。

平野｜それ、持って帰るなよ。先輩たちも見るんだから。

大山｜読むだけだ。

平野｜家でだろ。ここで読め。

大山は舌打ちして、立ったままページをめくった。
指は決勝のページの、武藤の欄で止まった。

大山｜2打席目、何で打ち取った。

平野｜下の欄。球種もコースも書いてある。

大山は返事をせずに下の欄を読んだ。
それからファイルを閉じて、棚に押し込んだ。1段ずれていた。

日和｜大山くん、そこ違う。1つ下。

大山は黙って入れ直した。戸口で一度だけ振り返った。

大山｜平野。明日、セカンドの日だろ。ベースカバー、遅れんなよ。

戸が閉まった。日和が組分けの紙に、最後の名前を書いた。
俺はスコアブックを棚に戻し、机の脇に置いていたグラブを取った。

外では岡田がもう、ネットの前でバットを振っていた。
俺はグラブをはめながら、白い息の中へ出ていった。

翌日の練習の終わりに、投内連係が始まった。
1塁に走者役の1年を置いて、ノッカーがマウンドの前へ打球を転がす。
投手が捕って2塁へ投げ、2塁から1塁へ回す。

2組目のセカンドは、日和の紙のとおり俺だった。
マウンドには大山が立っていた。

1本目。打球が大山の正面から、少し3塁側へ転がった。
ショートが打球のほうへ寄ったので、2塁へは俺が入る。
打球の音と同時に、俺はベースへ走り出した。

ベースの手前で歩幅を詰め、左足のつま先をベースの角に置いた。
胸を大山へ向けたところに、球が来た。

捕った勢いのまま右足を出して、1塁へ投げた。
走者役の1年が滑り込んできたときには、球はもう手から離れていた。

1塁の先輩のミットが鳴った。
打者役の1年は、まだ1塁までの線の途中だった。

岡田｜平野、今の入り方、どこで覚えたんだよ。

平野｜中学で、ベースの手前で捕って、踏むのが遅れたことがある。
それから毎日、入る足だけやってた。

岡田は「地味だな」と言って笑った。
言い返す前に、マウンドから大山の声がした。

大山｜日和。明日の組分けも、セカンドは平野にしとけ。

日和｜明日は内野、3組目まであるけど。

大山｜こいつは入る場所がずれねえ。投げやすい。
捕りにくいとこに入るやつと組むと、俺の練習が減る。

日和は紙を出して、何かを書き足した。
大山はもう、次の打球を待ってグラブを構えていた。

返事をする代わりに、グラブの中で一度指を握った。
2塁の後ろへ戻って、次の打球に備えて腰を落とす。
さっきより少しだけ、低く。
