# 12月の記録（章間）

12月の練習後。5-25「父親たちと取材」と 5-26 の前の「二冊目」のあいだに置く短い場面です。

## 本文

12月。全体練習が終わるころには、部室の窓が白く曇っていた。
机では日和が、明日の組分けの紙を広げていた。

俺は今日のノックの記録を清書しながら、紙の空いた枠を見た。
誰がどこに入るかは、もう聞かなくても半分は分かった。

日和｜明日のノック、内野は2組。平野くんは2組目のセカンドね。

平野｜岡田は？

日和｜サード。三浦くんは外野。先輩に、返球を見てほしいって言われたって。

日和が紙の端を押さえたまま、鉛筆の尻で棚を指した。
言われる前に、俺は2段目からセロハンテープを取って渡した。

戸が開いて、冷えた空気と一緒に大山が入ってきた。
挨拶もせずに棚の前へ行き、対戦校のファイルを1冊抜いた。
龍成の分だった。

大山はそのまま、ファイルを脇に挟んで戸口へ戻りかけた。

平野｜それ、持って帰るなよ。先輩たちも見るんだから。

大山｜読むだけだ。

平野｜家でだろ。ここで読め。

大山は舌打ちして、立ったままページをめくった。
指は決勝のページの、武藤の欄で止まった。

大山｜2打席目、何で打ち取った。

平野｜下の欄。球種もコースも書いてある。

大山は返事をせずに下の欄を読んだ。
それからファイルを閉じて、棚に押し込んだ。1段ずれていた。

日和｜大山くん、そこ違う。1つ下。

大山は黙って入れ直した。戸口で一度だけ振り返った。

大山｜平野。明日、セカンドの日だろ。ベースカバー、遅れんなよ。

戸が閉まった。日和が組分けの紙に、最後の名前を書いた。
俺はスコアブックを棚に戻し、机の脇に置いていたグラブを取った。

外では岡田がもう、ネットの前でバットを振っていた。
俺はグラブをはめながら、白い息の中へ出ていった。
