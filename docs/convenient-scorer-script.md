# 5-8　便利な部員、特別な相手

本編初稿。「外周50周」の直後から、美空が平野を名字で呼ぶようになるまで。

## 本文

監督は、俺が戻ってきたのを確かめると、ベンチの端に置いてあった紙を引き寄せた。

白い紙だった。何を見せられるのかと思っていたら、そのまま俺の前へ押してきた。

美空｜さっきの質問、ここに書いて。

平野｜2塁に投げていいのはどういうときか、ですか？

美空｜そう。それ、父さんに渡すから。

鉛筆を持って「2塁」と書いた。その先で手が止まった。

「2つ欲しがって、ゼロにするな」。去年のファイルに挟まっていた、前の監督の資料と同じ言い方だった。だから、今の監督もそれを読んだんだと思っていた。

でも、どういうときなら2塁でいいのか聞いたとき、監督は答えなかった。今、その答えを父親に聞こうとしている。

給水台のほうから、空のボトルをかごに入れる音がした。監督は紙の端を押さえたまま、俺の字が増えるのを待っていた。

……まさか。

平野｜今日の指示も、お父さんに聞いたんですか？

美空｜うん。昨日。

あまりあっさり返ってきたので、今のが答えだったのかと思って、監督の顔を見た。

監督はもう、俺の後ろを見ていた。声が届くか確かめるように、給水台のほうへ顔を向けてから、少し身をかがめた。

美空｜あ……あと。父さんに聞いてること、内緒にして。

平野｜先輩たちも知らないんですか？

美空｜ちょ、声。……誰にも言わないで。

平野｜……はい。

監督は「2塁」とだけ書いた紙を指で押さえた。

美空｜こっちの続きは書いて。

いつからお父さんに聞いてるんですか、と言いかけて、給水台の中田先輩と目が合った。

先輩は自分のボトルを手に持ったままだった。飲む様子も、片づける様子もなかった。

次は50周じゃ済まない気がした。

質問の続きを急いで書いて、紙を渡した。書いたところを監督に見せるつもりで持ち上げたら、もう端をつまんで取られていた。

平野｜じゃ、失礼します。

監督が紙を折り終える前に、ベンチを離れた。

翌日、同じ紙が返ってきた。「2塁」の字は俺のままで、その下だけ、別の人の角ばった字が並んでいた。

塁の位置を描いた図まであった。打球を拾った場所と、そのときの走者の位置に、それぞれ小さな印がついていた。

昨日は、捕ってからどっちに投げるかを聞いたつもりだった。図を見ると、捕る前にどこまで見えているかで、答えが変わるらしかった。

平野｜監督、これ読みました？

美空｜聞いたの、そっちでしょ。読んでおいて。

監督は俺の指が止まっていた図に目をやった。それから、紙がもう俺の手にあるのを見て、手ぶらでベンチを出ていった。

それから、必要なときに、記録の写しや質問を書いた紙を渡すようになった。返ってくる紙には、ときどき、あの角ばった字が増えていた。

何度目かに、スコアブックの写しを渡すと、監督は俺が端に書いておいた名前を指でなぞった。

美空｜平野って、これ、君？

平野｜はい。俺のです。

監督は名前のところをもう一度見て、紙を折った。

何日かして、用具を片づけていると、ベンチの前で監督が手を上げた。

美空｜平野。この前の記録、ある？

平野｜はい。今、持っていきます。

隣で中田先輩が、転がってきた球に手を伸ばした。伸ばしたところで止まった。

中田｜……今、平野って言ったよな。

球はその手の下を抜けて、先輩の靴の向こうへ転がっていった。
