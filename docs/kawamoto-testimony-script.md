# 5-11　河本の証言

本編初稿。「河本の来校」に続く。回想は河本の証言に沿い、美空が口にしなかった事情までは見せない。

## 現在：河本が話し始める

大山｜いつから知ってようが、もう卒業しただろ。

大山はベンチの向こうを見た。監督は紙の束を持って、鞄を置いてある奥の腰掛けへ移っていた。

河本｜就任初日だ。あの日、誰も声をかけられなかったんだぞ。

河本さんはそこでいったん言葉を切った。大山がこっちを向くまで待ってから、続きを言った。

河本｜俺が聞くまでな。

## 回想：美空の就任初日

新しい監督が来るというので、部員はグラウンドに並んでいた。前の列から後ろまで、まだ好き勝手な話をしていた。

部員｜神条監督、解雇だってよ。

別の部員｜マジかよ。別に大したことなんてしてねえのにな。

部員｜次の監督が来ても、やることは同じだろ。

風が白線の上の土をさらった。その向こうから、長い黒髪の女が歩いてきた。

光が、肩からこぼれた髪の縁を細くなぞった。列の前で足が止まり、伏せていた顔が上がった。

空も白線も、いつもの色のままだった。その人の顔だけが、初めて見る景色のように鮮やかだった。

部員｜おいおい、女かよ。

別の部員｜てか、めちゃくちゃ美人じゃね？

部員｜最高じゃん。

別の部員｜……野球できんのか？

河本｜……う、美しい……。

河本の声も、隣に聞こえるかどうかだった。風がやんだあとも、彼女の手にある紙の端は少し揺れていた。

河本｜監督。今年の目標、聞いてもいいですか。

美空｜も、目標？

美空は紙から顔を上げた。河本と目が合うと、その横にも同じようにこちらを見ている顔が並んでいた。

河本｜はい。前の監督は、甲子園出場だって。

美空｜あ……。ええと……1番。

河本は聞き返す前に、隣の選手を見た。隣の選手も、同じことを聞いたという顔をしていた。

河本｜1番って、甲子園で優勝するってことですか？

美空｜……はい。

さっきまで声も出なかった列が、そこでざわついた。

部員｜でも監督、うちは県でベスト4ですよ。

美空｜父さんが……。あ、いえ。1番になれたら……私も、やっと落ち着けるから。

河本｜落ち着くって？

美空｜家で……一緒に暮らせたら……。

誰かが帽子を持ち直した。その音が聞こえるほど、周りが静かだった。

美空は顔を上げた。話を終えたつもりだったのか、まだ全員が自分を見ているのに気づくと、慌てて手元の紙に目を落とした。

いちばん上の行を見つけると、紙の端を押さえていた手に力を入れた。

美空｜……まず外周。走って。

河本が走り出すと、少し遅れて、後ろの列が動いた。

部員｜……誰と？

別の部員｜優勝したあとの話だよな。

河本は後ろを見かけたが、すぐ前の選手に追いついて、いったん足を緩めた。

校舎の角を曲がるころには、前のほうでも、声を落として何か話していた。

1周目が終わるころには、列の前のほうから「結婚」という言葉が聞こえた。

## 現在：回想を聞き終える

河本さんが話し終えた。監督はもうベンチの奥で、鞄の中を探っていた。

大山｜ちっ……俺の知らない美空を……。

河本さんは大山の顔を見て、さっきまでよりずっと機嫌がよくなった。

俺には、話を聞く前より分からなくなったことがあった。

**選択肢：平野が聞き返す／大山の反応を待つ**

## A：平野が聞き返す

平野｜でも、誰と暮らすかは言ってないですよね。

河本｜そうだよ。

河本さんがあっさり認めたので、俺はてっきり、その先は自分でも分からないと言うのかと思った。

平野｜じゃあ、結婚って言ったのは――

河本｜お前、あそこで本人にその先まで言わせるのか？

むしろ俺のほうが気の利かないことを言ったみたいな顔をされた。

近くにいた先輩まで、かごを持ったまま小さくうなずいた。

## B：大山の反応を待つ

大山はベンチの奥にいる監督を見た。それから河本さんのほうへ向き直った。

大山｜待てよ。結婚って言われたわけじゃねえだろ。

河本｜あそこでその先まで言わせるなよ。

大山｜言われてねえんだな。

河本｜お前、その場にいなかったもんな。

大山は口を開きかけた。そのまま何も言わず、視線をそらした。

河本さんは、今度は笑うのを隠さなかった。

## 合流：河本が美空のもとへ戻る

河本さんは上着の襟を直した。大山に向かって張っていた声を落とし、ベンチの奥へ戻っていった。

監督の膝にあった練習メニューの下から、さっきの新聞の角が、まだ少しだけのぞいていた。
