# 5-18　大山の負傷

本編初稿。1年目の地方大会準決勝、清峰戦。試合前の大山の練習と、負傷から試合後の診断まで。

## 本文

準決勝までの数日、大山は全体練習が終わってからも走っていた。外野のポールから反対側のポールまで。俺が用具を倉庫へ運ぶあいだに、何度も目の前を横切った。

試合の前日、俺が倉庫の鍵を閉めたときも、まだ走っていた。帰り支度を済ませた中田先輩が、グラウンドの出口で声を張った。

中田｜大山、明日も試合だぞ。もう切り上げろ。

大山｜俺が先輩と同じとこでバテると思ってんのか。

中田先輩は振り返った。何か言いかけたが、大山がまた走り出したので、そのまま帰った。

その晩。大山は家の前でも、目印にした電柱まで何本もダッシュしていた。最後の1本を終えて家の前まで戻ると、両手を膝について笑った。

大山｜（ふふ……美空との結婚も見えてきたな。）

大山母｜翔！　さっきから呼んでるでしょ。いい加減、夕飯食べなさい！

大山｜うるせえババア！　人の恋路を邪魔すんな！

大山母｜誰がババアだ！　もう下げるよ！

夕飯を下げられると聞くなり、大山は玄関の段を駆け上がった。右足をついたところで足首がずきっと痛み、戸枠に手をついた。

大山｜痛っ……。食う！　下げんな！

靴を脱いで足首を回した。まだ痛んだが、台所から皿を重ねる音がしたので、足のことは忘れてそっちへ急いだ。

翌日。清峰との準決勝。8回表、4対2。俺は清峰の攻撃の欄に、続けて入った2人の走者を書いた。2アウトでも、右中間を抜かれれば同点になる。

マウンドの先輩が、2塁の走者を振り返ってから投げた。

打った瞬間、センターが右へ走った。ライトの大山はもう背中を向けて、フェンスへ向かっていた。

センターのほうが打球に近く見えた。なのに、落ちてくる球の下に先に入ったのは大山だった。

フェンスの手前で、大山が跳んだ。

白球がグラブに消えた。俺はアウトを書こうとして、鉛筆を止めた。

着地した右足が、内側に折れたように見えた。大山はそのまま肩からフェンスにぶつかり、金網を鳴らした。

先に着いたセンターが腰をかがめた。その横から、大山のグラブだけが上がった。ボールは入ったままだった。

塁審がアウトを告げた。応援席から歓声が降ってきた。ライトの大山は起き上がらなかった。

日和がベンチの外へ出かけて、足を止めた。球審が係員を呼ぶ声がした。

俺はようやく「右飛」と書いた。普段なら、その字を書き終えるころには、大山はもうベンチに戻ってきている。

大山を乗せた担架が引き揚げてくると、みんなが通路を空けた。大山はグラブを外して、迎えに出た中田先輩に渡した。

大山｜球、入ってるからな。

中田｜見てた。アウトだ。

大山はそれを聞いてから、担架の上で顔を伏せた。

9回表、ライトには大山の代わりの選手が立った。最後の打球は内野のゴロだった。試合が終わって、4対2のまま決勝に進んだことを記録した。

日和と病院に着いたときには、外はもう暗くなりかけていた。日和はベンチから持ってきた大山の帽子を、待合室でも膝の上に置いていた。

診察室で大山の右足を見ると、靴がなく、足首は固定されていた。大山は医者のほうを向いていた。いつも誰かに何か言われると途中で口を挟むのに、今度は最後まで待っていた。

医者｜右足首の骨が折れています。全治の目安は半年です。

大山は自分の右足を見た。まるで、ほかにも悪いところがないか探すみたいに、膝から下をゆっくり見直した。

大山｜この俺が怪我だと？　今まで怪我どころか、病気だってしたことのない俺様が……。

平野｜うん、君ってそんな感じだよね。

大山は俺を見なかった。しばらくして、医者に聞いた。

大山｜……次の試合、出られないのか。

医者｜出られません。

大山は口を開きかけた。いつもなら、できないと言われたことほどやると言うやつが、そのときは何も言わなかった。

日和が大山の帽子を差し出した。大山は受け取ると、つばを自分のほうに向けて膝に置いた。

俺の鞄には、最後のアウトまで書いたスコアブックが入っていた。その次のページは、まだ誰の名前も書いてなかった。
