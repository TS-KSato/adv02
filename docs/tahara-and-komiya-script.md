# 5-26　田原と小宮

本編初稿。2年目の春。新入生2人に会う朝から、5月の帝嶺学院との練習試合まで。

## 共通：グラウンドの入口

大山は、大柄な新入生の前で足を止めた。見上げるほどではないが、横に並ぶと、大山より肩幅があった。顔つきは穏やかで、急に前に立たれても、ミットを拾ってからゆっくり顔を上げた。

大山｜それ、お前のか。俺の球、受けてみろよ。

田原｜はい。田原大地です。よろしくお願いします。

大山はもうグラウンドへ入っていた。田原は頭を上げ、マスクを持ってそのあとを歩き出した。

入口の端にいたもう1人が、俺に会釈した。

小宮｜小宮裕也です。ショートをやってます。あの、今の、大山先輩ですよね？

平野｜そうだけど。

小宮｜じゃあ僕も、あっちに行きます。強い打球を捕る練習がしたかったんです。

小宮はそう言って、俺が返事をする間に、大山に声が届くところまで小走りで追いついた。日和がボールのカゴを置くと、内野ではノックが始まった。横のブルペンでは、田原がマスクをかぶって腰を落とした。

**選択肢：田原の捕球練習を見に行く／小宮の用事を手伝う**

## A：田原の捕球練習を見に行く

俺がブルペンの横に着くと、大山の1球目が低く来た。先輩捕手でも受ければミットが下がるあたりだ。田原は手首を少し返しただけで捕り、その位置でミットを止めた。

大山｜おっ。俺の球、いきなり捕れるとはな。

田原｜そうですか。わりと普通の球だっぺ。

大山｜今のは1割だ。もう1球いくぞ。

田原｜はい。いつでもどうぞ。

大山が投げた瞬間、ブルペンの脇を歩いていた3年の先輩が足を止めた。さっきよりずっと大きな音がした。田原は同じ高さでミットを止め、立って球を返した。

ブルペン脇の通路を美空が通った。日和に部室の鍵を渡し、校門へ向かうところだった。田原はマスクを取り、通路に近いところまで出て頭を下げた。

田原｜監督、はじめまして。大地といいます。監督はえらいべっぴんさんですね。おらの嫁に来てくれませんか。

先輩｜何ぃ!?　こらぁ、1年！

通路にいた先輩だけじゃなかった。隣のブルペンでも誰かが「待てや！」と怒鳴り、内野からも先輩たちがこっちを向いた。美空はもう柵の角を曲がっていた。

大山｜死ね。

頬のすぐ横を、白いものがかすめた。俺が肩をすくめたときには、田原は首をすっと傾けていた。球は田原の後ろのネットに突き刺さり、支柱が鳴った。

田原は揺れるネットをちらっと見た。さっき挨拶したときと同じ顔で、先輩たちに向き直った。

田原｜先輩方も、監督に惚れてるんですか。分かります。

田原はうなずいてから通路を見た。もう誰もいなかった。

## B：小宮の用事を手伝う

小宮がノック用の球を拾い集めていたので、俺は空いたカゴを持ってそばへ行った。内野では、大山がバットを手に取ったところだった。

小宮｜大山先輩、1本お願いしてもいいですか。思いきり打ってください。

大山が三遊間へ打った。小宮は横へ飛びつく前に、打球が跳ねる場所へ1歩出た。低いバウンドをすくって立ち上がると、そのまま1塁へ投げた。

大山｜お前、足は使えるな。

小宮｜大山先輩に打ってもらえるなら、毎日でも鍛えられますね。

大山が次の球を取りに戻ったところで、別の組のボールが、通りかかった美空の足元まで転がった。美空が立ち止まる。小宮は俺の手からカゴを取ると、その球を拾いに走った。

小宮｜監督、お手を煩わせません。

美空｜助かる。

平野｜（小宮くん、出世が早そうだな。）

美空は空いた両手をそのまま上着のポケットに入れて、歩いていった。小宮はカゴへ球を戻した。俺にカゴを返すときまで、口元が緩んでいた。

## 合流：5月、帝嶺学院との練習試合

5月。帝嶺学院との練習試合で、大山が先発した。最初の回、田原のミットが鳴るたび、帝嶺のベンチでは次の打者が素振りをやめてマウンドを見た。田原は1球受けるごとに、大山の胸へ球を返した。

途中からショートに入った小宮は、左中間への打球で、外野からの返球を受けた。捕ると同時に3塁へ投げたので、1塁から走ってきた選手は2塁を回ったところで足を止め、ベースへ引き返した。

試合が終わって道具を片づけていると、小宮が帝嶺の新庄を見つけ、帽子を取って近づいた。

小宮｜新庄さん。鳳翔の小宮です。ご挨拶が遅くなりました。

新庄｜小宮くん、だよね。さっきの中継、早かったね。

小宮｜ありがとうございます。母が、いつも御社に……。

新庄が「御社？」と聞き返す前に、帝嶺の選手が用具を運ぶのを手伝ってくれと声をかけた。

新庄｜ごめん。また対戦したときに。

新庄が道具を取りに行くと、小宮は帽子をかぶり直した。俺がそばを通ったときには、もう鳳翔の荷物を持ち上げていた。

俺は新しいスコアブックに、途中から入った小宮の名前を書き足した。田原の名前は、先発の欄に最初から書いてあった。
