# 5-35　公開求婚

本編初稿。優勝インタビュー。美空が口を開く直前まで。

## 本文

歓声がようやく落ち着いてきたころ、係の人が大山をベンチ前へ呼んだ。マイクを持ったインタビュアーの後ろに、テレビカメラが1台ついてきた。

俺はスコアブックを抱えて、日和とベンチの出口に立った。監督はその少し先で、インタビューが終わるのを待っていた。

インタビュアー｜9回のホームラン、お見事でした。内角の厳しい球でしたね。

大山｜俺様ほどならあれくらい楽勝だ。それよりマイク寄こせ。

鳳翔の応援席から拍手が起きた。大山はそっちを見ずに、インタビュアーの手元へ手を伸ばした。

インタビュアー｜えっ、ちょっと――

インタビュアーが言い終える前に、大山はマイクを取った。

大山は体ごと監督のほうを向き、マイクを口元に上げた。

大山｜美空！　待たせたな！　甲子園で優勝したぞ。俺と結婚だ！

「俺と結婚だ！」が、スピーカーから外野席まで響いた。グラウンドでまだ笑っていた先輩たちの声が、そこで途切れた。

スタンドのどこかから「おおーっ！」と声が上がった。拍手がその声を追いかけるように広がり、今度は相手側のスタンドからも口笛が鳴った。

先輩｜ああああっ！　大山、お前、先に言うなぁ！

大山の後ろにいた先輩が、飛び出しかけて隣の選手にぶつかった。ぶつかられたほうも同じ方向へ飛び出しかけていた。

鳳翔の応援席。手すりから身を乗り出した中田が、首に掛けていたタオルを両手で引っ張った。

中田｜そいつの前に俺のファイルを読んでください、監督ーっ！

帝嶺のベンチ前で、新庄は脱いだ帽子を手に持ったまま、大山を見ていた。

新庄｜け、結婚？　……はは……すごいな、彼は。

インタビュアーが大山に手を差し出した。大山はマイクを返し、美空のほうへ顎をしゃくった。カメラが監督に向き直ると、ベンチの出口で、日和が息を吸う音が俺のすぐ隣で聞こえた。

監督は大山のほうを向いた。口元が緩んだだけじゃなかった。目を細めて、歯が見えるほど笑った。俺は監督があんなふうに笑うところを、初めて見た。

大山｜（ほらな。）

監督は差し出されたマイクを両手で受け取った。
