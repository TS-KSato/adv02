# 5-24　剛の目撃

本編初稿。秋の休日、駅前。平野が聞けた会話を、大山は離れた場所から見ている。

## 共通：駅前

駅前の店で替えの鉛筆を買って出ると、前を歩く人が、ベンチに紙袋を置いた。片手でスマホを出し、もう片方の手で、隣にいる男に何か頼んでいる。

美空監督だった。学校では見ない服だったが、返事を待たずに次の用事を言い始めるところで分かった。

美空｜剛、次あそこ。駅の反対側。

黒いスーツの男は、箱を抱えたまま振り向いた。首が太くて、上着の肩が張っていた。眉のあたりが誰かに似ていると思ったら、厳さんだった。

剛｜姉ちゃん、俺、友達の結婚式からそのまま来たんだけど。これ置きに帰っていい？

美空｜あの店だけ。すぐ終わるから。

剛は箱を抱え直した。手首には、引き出物の袋までぶら下がっていた。

駅前の通りを挟んだ反対側に、大山がいた。自販機の横で足を止め、肩のあたりまでしか見えない人混みの奥をのぞいていた。

大山｜（な、なんだ、あの男は……？）

美空が駅の向こうの看板を指した。剛がそちらを見ようと首を回す。その視線が、大山のいる自販機のあたりを横切った。

大山｜（気づいただと？　この距離で……ただ者じゃねえ。）

大山は自販機の陰へ半歩ずれた。剛は看板を確かめてから、美空に「駅の中、通ったほうが早いよ」と言った。

俺が歩道へ戻ったときには、二人とも駅へ歩き出していた。さっき美空が置いた紙袋だけが、ベンチに残っていた。

**選択肢：先に選手へ弟だと伝える／先に美空へ荷物を届ける**

## A：先に選手へ弟だと伝える

大山が横断歩道を渡ってきた。少し後ろに、同じ部の先輩がいた。

大山｜平野。あいつ、美空とどういう関係だ。

平野｜弟だよ。「姉ちゃん」って聞こえた。

先輩｜弟なら、監督が何もらうと喜ぶか知ってるよな。

大山は先輩を見た。それから駅の入口を見て、今度は俺を見た。

大山｜平野。あいつと話すときは、先に俺を呼べ。

俺がベンチから紙袋を取ると、剛が一人で戻ってきた。美空が袋を置いてきたことに気づいて、取りに行かされたらしい。剛は両腕がふさがったままだったので、俺は紙袋の持ち手を、引き出物の袋と同じ手首に通した。

## B：先に美空へ荷物を届ける

紙袋をつかんで駅の入口まで走ると、美空と剛は案内板の前にいた。後ろから誰かが走ってくる音がした。

平野｜監督。これ、ベンチにありました。

美空｜あ、それ私の。ありがとう、平野くん。

美空は袋を受け取って、そのまま剛のほうへ差し出した。剛は持ち直した箱の上に袋を載せた。

俺が振り向くと、追いついてきた大山と先輩が駅の入口に立っていた。

先輩｜監督、あの人の前でもお前のこと平野くんって呼んでたな。家族ぐるみか？

平野｜今初めて会いましたよ。監督の弟です。

大山｜弟だってことまで知ってるじゃねえか。

## 合流：駅の向こうへ

駅の通路を向こうの出口へ歩いていく二人の背中が見えた。少し先を行く美空が立ち止まるたび、剛も、抱えた箱を落とさないように立ち止まった。

隣では、大山がまだその背中を見ていた。
