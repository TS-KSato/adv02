# 5-24　剛の目撃

本編初稿。秋の休日、駅前の広場。平野はベンチのそばで挨拶し、大山は約100m離れたバス停から二人を見ている。

## 共通：駅前

休日、買い物を済ませて駅前の広場を歩いていると、ベンチのそばに美空監督がいた。隣の男に声をかけながら、手に持っていた紙袋をベンチに置いた。

男は黒いスーツで、大きな箱を抱えていた。上着の肩が張っていて、眉のあたりが厳さんに似ていた。俺が通りかかったとき、二人の話がすぐそばで聞こえた。

美空｜剛、もう1軒だけ付き合って。

剛｜姉ちゃん、俺、結婚式の帰りだから荷物があるんだって。

美空｜あの店だけ。あんたが帰ってるときくらいしかできないから。

俺が足を止めると、監督がこっちを向いた。

平野｜あ、監督。こんにちは。

美空｜ああ、平野くん。これ、弟の剛。

平野｜はじめまして。野球部の平野です。

剛｜どうも。姉がお世話になってます。

剛は箱を落とさないように抱えたまま、頭を下げた。手首には引き出物の袋も掛かっていた。

広場の反対側。美空たちのいるベンチから100m近く離れたバス停に、大山がいた。

大山｜（美空だ。……なんだ、あの男は？）

ベンチのそばで、美空が次に行く店の看板を指した。剛が看板を探して顔を上げると、ちょうどバス停のほうを向いた。

大山｜（なっ、俺に気づいたのか？　この距離で……ただ者じゃねえ。）

大山は反射的にバス停の案内板の陰に入った。剛は看板を見つけると、美空について駅の入口へ歩き出した。

俺は二人を見送った。ふと横を見ると、美空が置いた紙袋がベンチに残っていた。紙袋に手を伸ばしたとき、バス停の案内板の陰から大山が飛び出した。部の先輩も追いかけてきた。何か叫んで大山を止めようとしたが、駅へ向かう二人を見た途端、先輩まで走る速度を上げた。

**選択肢：先に選手へ弟だと伝える／先に美空へ荷物を届ける**

## A：先に選手へ弟だと伝える

紙袋を手に取ったところで、大山が俺の目の前まで突っ込んできた。思わずベンチに膝の裏が当たるまで後ずさった。先輩もすぐ横に来たが、俺より先に駅の入口を見た。

平野｜うわっ。ちょ、ちょっと、どこから来たの？

大山｜ぜえ、ぜえ……お、おい、平野！　あの男、美空とどういう関係だ！

平野｜今、あのバス停から走ってきたよね？　え、あそこから見えてたの？　嘘でしょ？　……「姉ちゃん」って聞こえたけど。監督も弟だって言ってたよ。

先輩｜弟なら、監督が何もらうと喜ぶか知ってるよな。

大山は先輩を見た。それから駅の入口を見て、今度は俺を見た。

大山｜平野。あいつと話すときは、先に俺を呼べ。

俺が駅へ向かおうとすると、剛が引き返してきた。俺の手の紙袋を見て、「あ、それです」と足を止めた。

剛｜姉ちゃんに、取ってこいって言われて。すみません。

剛は箱を脇に抱え直し、空いた手で紙袋を受け取った。美空は駅の入口で待っていた。俺たちも剛について駅の入口まで歩いた。

## B：先に美空へ荷物を届ける

紙袋をつかんで駅の入口まで走った。美空と剛は中に入る手前で、案内板を見ていた。二人に追いついたところで、後ろから来ていた足音が止まった。

平野｜監督。これ、ベンチにありました。

美空｜あ、忘れてた。ありがとう、平野くん。はい、剛。

美空は受け取った紙袋を、そのまま剛の胸元に差し出した。

剛｜ちょ、ちょっと、姉ちゃん。俺、手ぇ空いてないって。

剛が箱を落としそうになりながら持ち手をつかむと、美空はもう袋から手を離していた。

二人が駅の中へ入ると、すぐ後ろで荒い息がした。振り向いたら大山の顔が目の前にあって、声が出た。先輩もその隣で、息を整えるより先に通路の奥をのぞき込んだ。

平野｜うわっ！　ちょ、ちょっと、いつからそこにいたんですか？

先輩｜お前、あの人の前でも平野くんって呼ばれてたな。家族ぐるみか？

平野｜さっき初めて挨拶したんです。監督の弟ですよ。

大山｜挨拶まで済ませてんのかよ。

## 合流：駅の向こうへ

駅の入口から、向こうの出口へ歩いていく二人の背中が見えた。美空が立ち止まって看板を探すたび、剛も箱と紙袋を抱えたまま足を止めた。

隣では、大山がまだその背中を見ていた。
