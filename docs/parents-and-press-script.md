# 5-25　父親たちと取材

本編初稿。秋の練習試合のあと。平野が球場の通路で見聞きした出来事。

## 本文

秋の練習試合が終わると、日和に頼まれて、俺は本部席までスコアの写しを届けに行った。戻ってくる途中、スタンド下の通路で、美空監督が記者につかまっていた。

記者は取材を始める前に、ちょうど通りかかった鳳翔の保護者にも話を聞いていた。

鳳翔の母親｜うちの子、あの決勝の日は帰ってきても何も言わなかったんです。次の朝には、もう練習に行きましたけど。

別の母親｜監督があんなに泣いてくれたでしょう。あの子たちも、ちゃんと見てもらえてたんだなって思いますよね。

「あんなに泣いてくれた」と聞こえたところで、監督が顔を上げた。それから、壁の時計を見た。

通路の向こうから、男が2人、こちらに歩いてきた。片方はスマホを持っていて、記者が次の質問をしかけたところで、監督の前に出た。

男｜あの、写真いいですか。できれば一緒に。

監督が返事をする前に、男はもう隣に並ぼうとしていた。監督は半歩下がった。そのぶんだけ、男も前に出た。

母親たちのそばにいた父親が、紙コップを窓枠に置いた。もう1人も、それを見て腰を上げた。

鳳翔の父親｜すみません。いま取材中なので。お話なら、こちらで。

声は穏やかだった。父親が通路の角を手で示すと、男たちは顔を見合わせた。それから4人とも角の向こうへ行った。監督は半歩下がった場所に立ったまま、記者のほうへ向き直った。

記者｜夏はあと1勝でした。来年に向けて、もう動き出しているんですね。

記者が見ていたのは、監督が手にしている練習試合の日程表だった。次の週末にも、朝から試合が入っている。

美空｜……朝からなんですよね。

監督は日程表を畳んで、ため息をついた。記者のペンはそこで止まらず、ノートの次の行へ進んだ。

さっきの父親が戻ってきた。窓枠に置いた紙コップを取り、自分の奥さんに渡した。もう1人も、飲みかけのコーヒーを持ってその隣に座った。スマホの男たちは戻ってこなかった。

俺と目が合うと、父親は軽く会釈した。俺も頭を下げた。

美空｜平野くん。もう帰っていい？

記者はまだ、ノートの最後の行を書いていた。
