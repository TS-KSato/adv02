# 5-34　甲子園初優勝

本編初稿。「最後のアウト」の直後。インタビューが始まる前まで。

## 本文

大山はマウンドを降りかけて、足を止めた。まだ1塁を見ていた。田原がマスクを外して走ってきて、大山の肩を両手でつかんだ。

田原｜大山先輩、勝ちましたよ。

そこで大山が笑った。何か言い返す前に、外野から駆けてきた先輩たちが両側から飛びついた。いつもなら振り払うところを、今度は大山も、空いたほうの腕で先輩の背中を引き寄せた。

1塁手が小宮を見つけて、ミットを掲げたまま駆け寄った。小宮はユニフォームについた土を払おうとしていたが、肩を抱かれると、その手で先輩の背中を叩いた。

鳳翔の応援席では、中田が立ち上がっていた。フェンス越しにグラウンドへ何か叫んで、もう一度跳ねた。隣の先輩が差し出したタオルに気づいたのは、顔を手の甲でぬぐったあとだった。

日和が俺の袖を離した。

日和｜平野くん、私たち……。

その先が出てこなかった。日和は口元を手で押さえたまま、もう一度グラウンドを見た。俺も隣で、すぐには返事ができなかった。

去年の夏、最後のアウトを書けずに、スコアブックを鞄にしまった。書くことは分かっているのに、今日も鉛筆の先がなかなか紙につかなかった。

膝の上のスコアブックを机に置いて、鉛筆を持ち直した。小宮が捕って、1塁へ投げた。俺は新庄の欄に「遊ゴロ」と書いた。その下に、鳳翔4、帝嶺3。

日和が机の端に手をつき、俺と一緒に数字を見た。

平野｜勝ったね。

日和｜……うん。

日和はうなずいてから、もう一度、今度は声を出して笑った。

球場の放送で、優勝校として鳳翔高校の名前が呼ばれた。グラウンドでは、やっと大山の顔が仲間の肩の間から見えた。

鳳翔高校、甲子園初優勝。
