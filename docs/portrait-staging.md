# 立ち絵の配置（冒頭・5-2〜5-12、中田の表情差分）

`game.js` の `cues`（`portrait`）で指定している立ち絵の配置と、配置を見送った箇所の記録です。本文は `c08-022` を作者決定の確定文に変えたほかは変えていません。行ID・分岐も変えていません。

## 方針

- 話者が変わるたびに切り替えず、平野が見ている人物と、その人物の居場所に合わせて出す。登場する行より前には出さない。
- 平野は一人称の視点人物なので出さない。
- 名前のない「先輩」「1年生」は、ほかの人物の立ち絵で代用しない（立ち絵なしで進める）。
- 美空の家庭用デフォルメ姿は、グラウンドの場面に使わない。
- 通常顔では本文と食い違う区間（激怒・大きな驚き・青ざめるなど）は出さない。
- 左右2枠まで。1人のときは右、2人のときは平野の視線が移った先や後から加わった人物を左に置く。
- キットは通ったルートではなく本文の並び順で立ち絵を戻す。5-2〜5-13 の各場面の最初の行で、左右の枠を明示する（分岐・合流・回想の開始と終了・場面転換で人物が残らない）。
- 表示の大きさは `game.css` のまま（高さ500px以下の画面は上半身寄り、PCは全身）。

## 中田の表情差分（第1便）の表示

キットは変えず、`game.css` で、画像名（と枠）を目印にこの3枚だけ表示を変えています。ほかの立ち絵の大きさは変えていません。本文欄の上端は「画面の高さ − 30vh − 56px」（本文欄の最小の高さと下の操作ボタンの列）として計算しています。

| 素材 | 表示 | ねらい |
|---|---|---|
| `nakata-practice-rage.webp`（激怒） | 右の枠を画面の中央に寄せ、画像の上端から硬球を握る拳の下（元画像の上から約750px）までが本文欄の上に収まる大きさ（通常の全身より大きい寄り）。画像は縦横比を保ち、引き伸ばさない | 平野から見た中田の寄り。湯気・顔・握った手・硬球が同時に読める。美空はこの間だけ出さない |
| `nakata-practice-bashful.webp`（照れ笑い・5-4） | 右に美空がいる左の枠だけ、元画像の上から520px（顔〜胸）を切り抜く。PC は切り抜きの下端を本文欄の上端に、高さの小さい画面は画面の下端にそろえる | 着席しているので、立った脚と手に下げたグラブを見せない |
| 同（照れ笑い・5-7） | 通常の立ち絵と同じ全身 | 背筋を伸ばした立ち姿なのでそのまま |
| `nakata-practice-shock.webp`（驚き） | 足元（画像の下端）を本文欄の上の基準線にそろえ、人物全体を縮小。PC は場面名の札の上、高さの小さい画面は札の右にずらして本文欄の上端に足元をそろえる。頭は持ち上げない。左右反転しない | 前かがみの姿勢のまま、伸ばした手と球、伸びた顎が本文欄や札に隠れない |

`c08-022` の本文は、作者決定でボトルから硬球に変えました（「だって、中田先輩の手の中で、硬球が平たくひしゃげていた。裂けた赤い縫い目から、中身がのぞいていた。」）。`c08-009` の給水のボトルの音は変えていません。

## 確認方法

- `tests/game/data.js`：全行で、復元される立ち絵がその場面の中の指定と一致すること、使う衣装、回想と現在の区別、5-13以降に残らないことを確かめる。
- `tests/game/play.js`：667×375 と 1280×720 で、5-5・5-9 の両分岐・5-10・5-11 の回想と現在への復帰を進め、途中で保存した行のリロード後の「つづきから」で同じ人物が戻ることを確かめる。
- 中田の表情差分は、通常画面→差分→通常画面を実際に送り、差分の途中でリロードして「つづきから」で画像と専用の配置が戻ること、区間の後で解除されることを確かめる。激怒は拳の位置、照れ笑いは切り抜きの比率と顔の位置、驚きは足元・球・顎の位置で判定する。
