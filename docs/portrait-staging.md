# 立ち絵の配置（全編）

`game.js` の `cues`（`portrait`）で指定している立ち絵の配置と、意図して出さない区間・合う素材がなく見送った区間の記録です。配置は既存の素材だけで行い、本文・行ID・分岐・データ版は配置のために変えていません（`c08-021`〜`c08-022` の本文は、別の作者決定で確定文にしています）。

## 方針

- 素材があるという理由だけで出さない。話者が変わるたびに切り替えず、平野が見ている人物と、その人物の居場所・視線・場面の焦点に合わせて出す。登場する行より前には出さない。画面外の声だけの人物は出さない。
- 通常の会話や対面では人物を見せる。投球・打撃・走塁・守備を追う区間は、背景で進める（正面の通常の立ち絵を出し続けない）。
- 同じ場所の会話では、不必要に出したり消したりしない。場所・時代・服装・強い感情が本文と食い違う素材は使わない（泣く・大笑いする・驚く場面を通常顔で埋めない）。
- 試合中の選手・監督は試合用ユニフォーム、練習は練習着。引退後・卒業後の中田に現役の試合姿を出さない。
- 平野は一人称の視点人物なので出さない。
- 名前のない「先輩」「1年生」、記者・保護者・龍成選手・北陵監督・帝嶺監督・インタビュアー・三浦・岡田など立ち絵のない人物は、ほかの人物の立ち絵で代用しない（立ち絵なしで進める）。野原や厳を北陵監督に流用しない。
- 美空の部屋着（デフォルメ）は使わない。家の場面は厳だけを出す（平静な会話にデフォルメを機械的に当てない）。
- 通常顔では本文と食い違う区間（激怒・大きな驚き・青ざめるなど）は出さない。
- 左右2枠まで。1人のときは右、2人のときは平野の視線が移った先や後から加わった人物を左に置く。
- キットは通ったルートではなく本文の並び順で立ち絵を戻す。前の場面の人物が残る場面では、最初の行で左右の枠を明示する（分岐・合流・回想の開始と終了・場面転換・勝敗の経路で人物が残らない）。3人以上いる場面でも、左右2枠と場面の焦点で整理する。
- 表示の大きさは `game.css` のまま（高さ500px以下の画面は上半身寄り、PCは全身）。
