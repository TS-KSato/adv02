# 立ち絵の配置（冒頭・5-2〜5-12、中田の表情差分）

`game.js` の `cues`（`portrait`）で指定している立ち絵の配置と、配置を見送った箇所の記録です。本文は `c08-022` を作者決定の確定文に変えたほかは変えていません。行ID・分岐も変えていません。

## 方針

- 話者が変わるたびに切り替えず、平野が見ている人物と、その人物の居場所に合わせて出す。登場する行より前には出さない。
- 平野は一人称の視点人物なので出さない。
- 名前のない「先輩」「1年生」は、ほかの人物の立ち絵で代用しない（立ち絵なしで進める）。
- 美空の家庭用デフォルメ姿は、グラウンドの場面に使わない。
- 通常顔では本文と食い違う区間（激怒・大きな驚き・青ざめるなど）は出さない。
- 左右2枠まで。1人のときは右、2人のときは平野の視線が移った先や後から加わった人物を左に置く。
- キットは通ったルートではなく本文の並び順で立ち絵を戻す。5-2〜5-13 の各場面の最初の行で、左右の枠を明示する（分岐・合流・回想の開始と終了・場面転換で人物が残らない）。
- 表示の大きさは `game.css` のまま（高さ500px以下の画面は上半身寄り、PCは全身）。

## 専用の表示（`game.css`）

キットは変えず、`game.css` で、画像名（と枠）を目印に次の素材だけ表示を変えています。ほかの立ち絵はキットの既定（高さのある画面は画面の高さの78%で下端にそろえた全身、高さの小さい画面〈高さ500px以下〉は165%に拡大して上端にそろえた上半身寄り）のままです。本文枠の上端は「画面の高さ − 本文枠の高さ − 56px」です。

方針：切り抜きは使わない。元画像の下端で絵が切れている素材は、画像の下端を必ず画面の下へ出す（切り口を画面に出さない）。全身の素材は、足元を本文枠の上に浮かせない（足元は本文枠の後ろか画面の下）。半透明の本文枠は、切り口を隠す壁として扱わない。

素材の透明領域（描かれている範囲）を調べると、元画像の下端で絵が切れているのは `nakata-practice-rage.webp` だけで、ほかの45枚は全身が描かれています。

## 確認方法

- `tests/game/data.js`：全行で、復元される立ち絵がその場面の中の指定と一致すること、使う衣装、回想と現在の区別、5-13以降に残らないことを確かめる。
- `tests/game/play.js`：667×375 と 1280×720 で、5-5・5-9 の両分岐・5-10・5-11 の回想と現在への復帰を進め、途中で保存した行のリロード後の「つづきから」で同じ人物が戻ることを確かめる。
- 中田の表情差分と美空の動揺デフォルメは、通常画面→差分→通常画面を実際に送り、差分の途中でリロードして「つづきから」で画像と専用の配置が戻ること、区間の後で解除されることを確かめる。激怒は切り口が画面の下へ出ることと顔・拳の位置、照れ笑いは切り抜きがないこと・グラブが画面の下・顎が本文枠の上・美空より低い頭、驚きは足元・球・顎、デフォルメは大きさ・顔・足元の位置で判定する。
- 立ち絵の全使用区間：立ち絵の組み合わせが変わる全ての行を 667×375・844×390・956×440・1280×720 で表示し、実画像の透明領域から、切り抜き・切り口の露出・足元の浮き・頭の欠けがないことを確かめる。
